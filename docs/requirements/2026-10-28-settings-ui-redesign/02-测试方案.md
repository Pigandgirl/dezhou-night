# 设置弹窗UI重做测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-UI-01 | 桌面打开设置 | 620×704，分组清晰 |
| T-UI-02 | 检查开关 | 5个开关同尺寸，无竖排 |
| T-UI-03 | 检查下拉 | 视角/音量/音色统一样式 |
| T-UI-04 | 滚动内容 | 中间滚动，底部固定 |
| T-UI-05 | 点击开关 | 状态即时切换 |
| T-UI-06 | 修改音量 | 设置保存 |
| T-UI-07 | 手机374宽 | 标签单行、下拉全宽 |
| T-UI-08 | 页面错误 | 0 |

## 通过标准

- 无文字逐字换行；
- 内容不溢出弹窗；
- 底部按钮可见；
- 手机无横向滚动。
