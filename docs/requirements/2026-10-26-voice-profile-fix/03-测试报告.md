# 游戏播报音色修复测试报告

> 版本：1.1.2（versionCode 108）  
> 日期：2026-10-26  
> 环境：Edge/Playwright；生产页面；Android APK 解包  
> 无 Android 真机主观听感

## 1. 根因

1.0.103 为统一中英文播报，把所有动作播报改为系统 TTS，导致：

- 设置里选择的 8 套离线音色包不再被游戏动作用到；
- 多名女声/男声全部落到同一个系统 TTS 音色，只靠 pitch/rate 区分；
- 新增英文音频文件名 `en_*.mp3` 不匹配 `/voice` 路由正则，HTTP 404，英文没有音频。

## 2. 修复

- `speak()` 优先播放当前 `voiceProfile` 的离线音色包；
- 8 套音色各补充 39 段英文动作/数字音频；
- 中文和英文都从同一 profile 音频读取；
- 英文金额：one/two/.../nineteen/twenty/.../ninety/hundred/thousand；
- `/voice` 路由允许 `en_*.mp3`；
- TTS 仅做 fallback，并按 profile 选基础发音人；
- Android NativeBridge 每次 speak 前重新应用 voiceProfile。

## 3. 音色包加载测试

```text
male_deep:
  voiceBuffers = 63
  en clips = 39

female_bright:
  voiceBuffers = 63
  en clips = 39
```

每个 profile 共 63 段（24 中文/旧 + 39 英文）。

## 4. 播报路径测试

### 英文

强制随机英文，`speak('raise', 150)`：

```text
captured = ['en_raise', 'en_one', 'en_hundred', 'en_fifty']
speakSystemText = 0
```

### 中文

强制随机中文，`speak('raise', 150)`：

```text
captured = ['raise', 'one', 'hundred', 'five', 'ten']
speakSystemText = 0
```

### 切换音色

```text
male_deep -> female_bright
secondBuffers = 63
secondEn = 39
profile = female_bright
```
