# 游戏播报音色修复需求文档

> 状态：已实现并部署 1.1.2  
> 日期：2026-10-26

## 背景

用户反馈：游戏内动作播报没有使用设置中选择的音色。

1.0.103 曾把中文/英文动作播报统一切到系统 TTS，导致：

- 内置 8 套离线音色包没有被游戏播报使用；
- 不同女声/男声可能落到同一个系统 TTS 音色；
- 选中 male_deep、female_sweet 等只是改变音高/语速，听感不是该音色；
- `/voice` 路由只允许 `[a-z]+.mp3`，新增的 `en_*.mp3` 英文音频会被 404。

## 目标

- 游戏动作播报严格使用用户在设置里选择的音色；
- 中文和英文都使用同一套音色，避免两个播报员；
- 音色包加载失败时才回退 TTS，回退也必须选同一音色角色；
- 保留随机中文/英文播报；
- 不改变奖杯/成就/牌局逻辑。

## 需求

- **R1** 动作播报优先播放当前 `voiceProfile` 的离线音色包。
- **R2** 中文动作、金额使用所选音色包。
- **R3** 英文动作、金额使用同一套所选音色包。
- **R4** 每套 8 个音色都必须有英文 clip。
- **R5** 音色切换后下一次播报立即使用新音色。
- **R6** 音色包失败才允许 TTS fallback。
- **R7** TTS fallback 按每个音色选择对应基础发音人，而不是只改 pitch。
- **R8** Android NativeBridge 每次 speak 前应用当前 voiceProfile。
- **R9** `/voice` 路由允许 `en_*.mp3` 文件名。
- **R10** 不出现两个播报员。
- **R11** 保留中文/英文随机选择。

## 验收

- **AC1** 选择 male_deep 后加载该 profile 音色包。
- **AC2** 音色包包含中文动作/数字和英文动作/数字。
- **AC3** 强制中文随机时播放中文 clip，不调用 TTS。
- **AC4** 强制英文随机时播放英文 clip，不调用 TTS。
- **AC5** 切换 female_bright 后加载 female_bright 音色包。
- **AC6** 页面无 JS 错误。
- **AC7** APK 包含 en_* 音频。
- **AC8** 生产 `/voice/.../en_*.mp3` 返回 200。
- **AC9** 1.1.2 构建部署。

## 非目标

- 不重新录制成就/系统提示等任意文本；
- 不改变音色包的音色设计；
- 不改变音乐/音效；
- 不在本轮做真机主观听感验收。
