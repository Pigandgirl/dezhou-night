# 游戏播报音色修复测试方案

## 用例

| 编号 | 需求 | 步骤 | 预期 |
|---|---|---|---|
| T-VOICE-01 | R1/R2 | 选择 male_deep，加载音色包 | 46+ clip，含中文与英文 |
| T-VOICE-02 | R3/R4 | 强制英文随机 speak raise 150 | 调用 en_raise/en_one/en_hundred/en_fifty |
| T-VOICE-03 | R2 | 强制中文随机 speak raise 150 | 调用 raise/one/hundred/five/ten |
| T-VOICE-04 | 不调用 TTS | stub speakSystemText | system=0 |
| T-VOICE-05 | R5 | 切 female_bright 后加载 | 使用 female_bright 包 |
| T-VOICE-06 | R9 | 请求 `/voice/male_deep/en_check.mp3` | 200 |
| T-VOICE-07 | AC6 | 页面 pageerror | 0 |
| T-VOICE-08 | AC7 | 解包 APK | 包含 en_* 音频 |
| T-VOICE-09 | AC8 | 生产请求 en clip | 200 |
| T-VOICE-10 | AC9 | 构建/部署 | 1.1.2 |

## 环境

- Edge/Playwright；
- 本地 server；
- 无音频主观听感设备；
- Android 构建用 aapt2/apksigner。

## 命令

```powershell
node --check src/audio.js
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1 -VersionName 1.1.2
```

## 通过标准

- 选中 profile 后加载对应音色包；
- 中文/英文均播放 clip；
- 不调用 TTS；
- 切 profile 立即生效；
- 生产英文音频 200；
- 页面无错误；
- APK/线上更新。
