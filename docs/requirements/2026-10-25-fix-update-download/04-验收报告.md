## 遗留问题与风险

1. 用户当前停留在 1.0.82，旧版内没有新下载逻辑，第一次必须手动安装 1.0.85。
2. 新版本首次安装时，系统可能要求「允许安装未知应用」，这是 Android 正常权限流程。
3. 当前均无真实 Android 设备，DownloadManager/安装器交互没有真机点击录像证据。
4. APK 下载仍使用 HTTP IP 地址；新版通过 WebView 已可读取，但长期建议绑定域名和 HTTPS。

更新失败的直接原因和传输链路已修复：不再依赖失败的 DownloadManager/HttpURLConnection 首选路径，改成游戏 WebView 已验证可用的网络栈下载，并由前端分片写入原生更新文件。代码、构建、字节完整性和失败兜底均通过测试；唯一未验证项是真机系统安装器点击。
