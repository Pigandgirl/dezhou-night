# 麦克风旁显示正在发言玩家昵称测试报告

> 版本：1.1.26（versionCode 133）  
> 日期：2026-10-28  
> 环境：本地在线好友房 + Edge/Playwright 1400×800

## 1. 实测

```text
麦克风按钮 visible=true
标识文字：在线甲正在发言
标识位置：[1168, 31]
麦克风位置：[1282, 22]
标识右边缘到麦克风左边缘：8px
等待5秒：仍显示
释放说话权后：hidden=true
pageerror=0
```

截图：`evidence/speaker-near-mic.png`

## 2. 实现

- 将 `#voiceSpeaking` 从页面上方移到 `.hud-actions` 内，麦克风按钮左侧；
- 文案由 `${name} 正在说话` 改为 `${name}正在发言`；
- 自己发言也使用服务端返回的昵称，不再替换成“你”；
- 删除4.3秒 setTimeout；只在服务端 `voice-active` 释放时隐藏；
- 长昵称最大宽度约210px，手机窄屏145px，省略号截断。
