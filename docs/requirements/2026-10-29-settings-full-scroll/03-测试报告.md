# 设置弹窗整页滚布局测试报告

> 版本：1.1.32（versionCode 139）  
> 日期：2026-10-29  
> 环境：本地 server + Edge/Playwright 1400×800 / 390×844

## 1. 顶部初始

```text
弹窗 top=24，height=752（max 94vh）
整页 scrollHeight=916
可视内容区 clientHeight=750
标题高54px，top=25
底部按钮 top=885（在视口外，跟随内容）
```

截图：`evidence/scroll-1-top.png`

## 2. 滚动中段

滚动80px：

- 标题已开始离开视口；
- 内容直接占满弹窗；
- 底部按钮仍未吸底。

截图：`evidence/scroll-2-middle.png`

## 3. 滚动到底部

最大滚动166px：

```text
标题 top=-141（已离开视口）
底部按钮 top=719（随内容出现）
```

截图：`evidence/scroll-3-bottom.png`

## 4. 手机

390×844：

- 紧凑标题；
- 单列设置内容；
- 底部按钮在内容流中，不悬浮遮挡；
- 页面可滚动。

截图：`evidence/scroll-4-mobile.png`

## 5. 实现

- `.settings-modal-v2` 改为整页 `overflow-y:auto`；
- `.settings-head` 改为 static，高度压缩到54px；
- `.settings-scroll` 不再独立滚动；
- `.settings-foot` 改为 static；
- 关闭按钮、随机主题、设置功能全部保留。
