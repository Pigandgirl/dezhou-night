# 设置弹窗整页滚布局测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-SCRL-01 | 打开设置顶部 | 标题小，内容尽可能多 |
| T-SCRL-02 | 滚动80px | 标题开始离开视口 |
| T-SCRL-03 | 滚动到底部 | 底部按钮在内容流中 |
| T-SCRL-04 | 检查底部是否吸底 | 不吸底 |
| T-SCRL-05 | 手机390×844 | 单列滚动正常 |
| T-SCRL-06 | 修改设置 | 功能仍生效 |
| T-SCRL-07 | 页面错误 | 0 |

## 通过标准

- 顶部/底部不固定；
- 中间可操作区域尽量大；
- 四张状态截图完整可验证。
