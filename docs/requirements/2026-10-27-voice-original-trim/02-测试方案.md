# 原速播报与称呼/操作无缝衔接测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-VO-01 | 单机 AI 开局，观察播报 | rate=1，无加速 |
| T-VO-02 | 记录称呼音频时长 | 尾部静音被裁掉 |
| T-VO-03 | 记录名称结束/操作开始 | 间隔≤50ms |
| T-VO-04 | 连续多手 AI 行动 | 名称+操作按序 |
| T-VO-05 | 页面错误 | 0 |
| T-VO-06 | 构建部署 | 1.1.11 |

## 测量方法

- 在浏览器中包装 `playBuffer`/`playActionKeys`，记录 `performance.now()`；
- `trimSpeechBuffer` 输出裁剪起点/播放时长；
- 不修改业务顺序，只观测。

## 通过标准

- rate 全部1；
- 操作开始时间不晚于名称结束+50ms；
- AI 连续动作无JS错误。
