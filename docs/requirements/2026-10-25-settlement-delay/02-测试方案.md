# 牌局结束结算延迟测试方案

## 范围

- HUD 15秒延迟；
- 结算总筹码摘要；
- 服务端结算宽限；
- 新一手/离开取消；
- gameover 不覆盖确认框；
- 页面错误；
- 构建。

## 不在范围

- 真机好友房/在线匹配完整对局；
- 真实玩家筹码归零；
- 多端并发；
- 服务端30秒关闭后的重连。

## 策略

- Playwright 单机页面加载 HUD；
- 直接调用 `showSettlement` 注入总筹码数据，检查摘要；
- 构造 settle 状态，调用 `maybeShowOnlineGameOver`；
- 立即检查 `onlineGameOver` 隐藏；
- 等待15.6秒后检查显示；
- 页面错误；
- 构建。

服务端宽限通过代码审查和语法检查；真实零筹码对局需真机复测。

## 用例表

| 编号 | 需求 | 步骤 | 预期 |
|---|---|---|---|
| T1 | R7-R9 | showSettlement | 总筹码/底池/归零玩家 |
| T2 | R1 | 调用后立即 | 确认框隐藏 |
| T3 | R1 | 等待15.6秒 | 确认框显示 |
| T4 | R2 | 延迟期间 | 结算可见 |
| T5 | R3 | 新一手 | 取消pending |
| T6 | R5 | 服务端nextHand | 先保留15秒再end |
| T7 | R6 | gameover时open | 不掀桌 |
| T8 | AC7 | pageerror | 空 |
| T9 | AC8 | 构建 | 1.0.98 |

## 命令

```powershell
node --check src/hud.js
node --check server/lib/game-engine.js
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

## 风险

- 真实零筹码状态由服务器触发，注入测试只能验证 HUD 行为；
- 服务端宽限需要真实对局或引擎单测；
- 15.6秒等待可能在慢设备上更久，但不会提前弹出。
