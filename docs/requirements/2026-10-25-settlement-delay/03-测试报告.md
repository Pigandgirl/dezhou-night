## 实际输出

```text
全桌总筹码 200 · 本手底池 48 · 筹码归零：B
```

截图：`evidence/settlement-with-total.png`。

### 确认框延迟

```text
调用 maybeShowOnlineGameOver 后立即检查：
onlineGameOver hidden = true

等待 15.6 秒后：
onlineGameOver hidden = false

pageerror = 无
```

说明结算面板先出现，确认框按15秒延迟弹出。

### 服务端宽限

`server/lib/game-engine.js` 的 `nextHand()` 修改：

1. 先计算仍可继续的玩家；
2. 少于2人时不立即清空结算；
3. 第一次进入 grace，`nextHandAt=+15s` 并广播；
4. 15秒后才 `endGame`；
5. 正常多人继续下一手逻辑不变。

服务端宽限未做真实零筹码对局测试，标记代码级验证。

### gameover 覆盖保护

`src/hud.js` 的 `service.on('gameover')` 增加：

```text
if (this.onlineGameOverOpen) {
  toast(...);
  return;
}
```

确认框已经显示时，服务端结束事件不会立即掀桌/隐藏结算。
