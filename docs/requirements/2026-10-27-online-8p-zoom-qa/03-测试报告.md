# 在线8人模型与自由缩放测试报告

> 版本：1.1.14（versionCode 121）  
> 日期：2026-10-27  
> 环境：本地 server，8个QA账号，Playwright 1400×800

## 1. 8人在线开局

```text
创建房间 = 成功
7个账号加入 = 成功
开始牌局 = 200 / ok
state.seats = 8
scene.playerCount = 8
```

8个在线玩家全部入座并开局成功。

## 2. 玩家模型

```text
场景 rigs = 7
rigs 中 null = 1（主角第一视角，不生成自己的人物模型）
7个对手 rig visible = [true,true,true,true,true,true,true]
```

因此：

- **没有模型缺失**；
- 8人局是“7个对手模型 + 第一视角本人”；
- 原始截图中人数较少/视角较近时，部分模型可能在镜头外，但不会从场景中消失。

截图：`evidence/eight-players-far.png`

## 3. 视角缩放

双指捏合后：

```text
userZoom = 2.8
mode = hero
camera distance to table look = 4.78
spectatorRadius = 2.35
```

玩家最远距离 **4.78**，大于观战视角半径 **2.35**，满足“最远和观战视角一样远/更远”。

7个对手 rig 在拉远后全部仍 `visible=true`，截图可见全部对手。
