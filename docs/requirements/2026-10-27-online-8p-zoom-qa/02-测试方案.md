# 在线8人模型与自由缩放测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-8P-01 | 创建8人好友房 | 创建成功 |
| T-8P-02 | 7个账号依次加入并连接SSE | 8人在线 |
| T-8P-03 | 房主开始 | 8人开局 |
| T-8P-04 | 读取 state/seats/scene | seats=8、playerCount=8、7个对手rig |
| T-8P-05 | 双指捏合 | userZoom=2.8 |
| T-8P-06 | 比较相机距离/观战半径 | 玩家远景≥观战 |
| T-8P-07 | 截图核对模型 | 7个对手模型全部可见 |

## 环境

- 本地 server；
- 8个QA账号；
- Chrome/Edge + Playwright 1400×800；
- 好友房8座。

## 说明

主角使用第一视角，不单独生成一个自己的人物模型；因此8人局场景内应为7个对手模型+第一视角本人。
