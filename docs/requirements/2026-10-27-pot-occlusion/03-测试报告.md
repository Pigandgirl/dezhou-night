# 底池数字被公共牌遮挡 — 测试报告

- 日期：2026-10-27
- 环境：Windows、Edge headless（Playwright/CDP）、本地沙盒 `127.0.0.1`
- 构建：`APP_VERSION=1.1.14`、`APP_VERSION_CODE=121`
- 结论：**本地 4 个视口布局通过；3D 大号底池标签已隐藏；生产未部署，AC6 阻塞**

## 1. 修复内容

| 文件 | 修改 |
| --- | --- |
| [src/layout.js](../../../src/layout.js#L107) | `POT_SPOT.z` 从 `-0.235` 改到 `0.3`，底池筹码堆移到公共牌前方（靠近玩家），屏幕投影随之下移 |
| [src/scene.js](../../../src/scene.js#L1163) | `potStack.setAmount(..., { label: false })`，隐藏 3D 大号底池数字，保留筹码堆 |
| [src/style.css](../../../src/style.css#L8925) | 移除 `.potbox { display:none!important }`，改为 `display:flex; z-index:12` |
| [src/style.css](../../../src/style.css#L9660) | 横屏 `.potbox { top: clamp(208px, 34vh, 300px) }`；竖屏 `top:110px` |
| [server/public/web/index.html](../../../server/public/web/index.html) | 重新构建，包含上述修改 |

## 2. 实际执行与真实输出

### 2.1 修复前（before）

命令：

```powershell
node qa\run-pot-layout.mjs before
```

真实输出（[evidence/pot-layout-before.log](evidence/pot-layout-before.log)）：

```text
desktop {"viewport":{"w":1440,"h":900},"rail":{"x":615,"y":126,"w":210,"h":71,"bottom":197},"potbox":{"display":"none",...},"potSpot":{"x":0,"y":0.782,"z":-0.235},"spriteScreen":{"x":720,"y":285,"visible":true,...}}
mobile-landscape {"viewport":{"w":852,"h":393},"rail":{"x":343,"y":126,"w":166,"h":42,"bottom":168},"potbox":{"display":"none",...},"potSpot":{"x":0,"y":0.782,"z":-0.235},"spriteScreen":{"x":426,"y":125,"visible":true,...}}
```

- `.potbox` 被 CSS 隐藏（`display:none`）；
- 唯一底池数字来自 3D `spriteScreen`；
- 852×393 下 3D 标签 y=125，落在牌栏 126–168 内 → 被公共牌遮挡；
- 1440×900 下 3D 标签 y=285，未压牌栏，但短横屏/移动端会遮挡。

修复前手机横屏截图：[pot-before-mobile-landscape.png](evidence/pot-before-mobile-landscape.png)

## 5. 未覆盖项与原因

- **生产真实页面**：没有 `DEPLOY_PASS`/SSH，无法发布；见 AC6。
- **Android/iOS 真机**：headless Edge 只能验证 DOM/投影，不能验证真机 GPU 文字清晰度和刘海安全区。
- **极短横屏（<360px 高）**：208px 底池条可能与行动条接近；本轮未测。
- **2D 客机牌桌 `.gt-pot`**：未改动，未回归；不属于本次 3D 牌桌问题。
- **真实牌局动画**：测试用 `hud.setPot`/`setBoardCards` 固定状态，未跑完整手牌；空间关系一致。
