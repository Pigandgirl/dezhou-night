# 02 测试方案：HTTPS 网址打开 + 语音说话

- 日期：2026-10-27
- 历史测试入口：`https://56f32046dd5f12.lhr.life/play`（测试时入口，已失效）
- 当前状态：临时隧道已停止；需要正式 HTTPS 才能复跑
- 对应需求：`01-需求文档.md` R1–R8、AC1–AC8

## 1. 范围

### 在测

| 项 | 内容 |
|---|---|
| 用户原始 URL | `https://192.144.159.220:8080/play` 是否可用 TLS |
| 临时 HTTPS URL | 是否返回生产牌桌、是否安全上下文 |
| 麦克风 | `getUserMedia` 是否返回音轨 |

- 真机 iPhone 双人语音、音质、回声、弱网。
- 24 小时稳定性/SLA。
- 生产域名、证书、独立服务器发布。

## 2. 测试策略

| 层级 | 方法 |
|---|---|
| 原始 URL | `curl -k https://192.144.159.220:8080/play` 观察 TLS 错误；HTTP 对照 200 |

| 安全上下文 | 页面内 `window.isSecureContext`、`location.protocol` |
| 麦克风 | Edge 启动参数 `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream`，调用 `getUserMedia` |

| 缓存 | 第一次加载后 reload，测 `window.__poker` 出现时间 |
| 稳定性 | 观察旧 URL 502/重启；记录新 URL |

## 4. 用例

| 用例 | 关联 | 步骤 | 预期 |
|---|---|---|---|
| T1 原始 HTTPS URL | R1 | `curl -k https://192.144.159.220:8080/play` | TLS 失败；HTTP 对照 200 |
| T2 临时 URL 打开 | R1/AC1 | Edge 打开 `https://<host>/play`，等待 `__poker` | 标题「德扑之夜」，大厅/登录层出现 |
| T3 安全上下文 | R2/AC2 | 读 `isSecureContext/location.protocol` | true / `https:` |
| T4 麦克风 | R3/AC3 | 假设备下 `getUserMedia({audio:true})` | 1 条 `live` 音轨 |
| T5 Manifest | R1 | 读 `<link rel=manifest>` 并 fetch | 200，scope `/play`，display standalone |
| T6 二次缓存 | R5/AC5 | 首次加载后 `Page.reload`，计时 | `__poker` < 15s |
| T7 房间 SSE + 语音 WSS | R4/AC4 | 本地沙盒建房间，localhost.run 隧道；先取房间 SSE，再 Node WebSocket 连 `/api/voice-relay` | SSE 200/text-event-stream；WSS 101/OPEN，发送一帧成功 |
| T8 Loader 本地 | R1 | `http://127.0.0.1:18080/play` 打开 | `document.write` 后 `__poker` 存在 |
| T9 无警告页 | R6/AC6 | 看页面标题/正文 | 直接牌桌，不是 Serveo/Pinggy 警告 |
| T10 隧道稳定性 | R7/AC7 | 持续访问旧 URL | 记录 502/重启；新 URL 可用 |
| T11 WebKit/Safari 引擎 | R1/R2 | Playwright WebKit + iPhone 13 打开临时 URL | `__poker` 存在、`isSecureContext=true`、无 pageerror |

## 5. 执行命令

```powershell
# 1) 本机代理（缓存生产 HTML，分块 + gzip）
node qa/tunnel-proxy.mjs

# 2) 新开一个终端，localhost.run 隧道；记下输出的 https://xxxx.lhr.life
ssh -tt -o StrictHostKeyChecking=accept-new -o ServerAliveInterval=30 `
  -R 80:127.0.0.1:18080 nokey@localhost.run

# 3) HTTPS 页面 + 安全上下文 + 麦克风 + 缓存
$env:HTTPS_URL='https://xxxx.lhr.life'
node qa/run-https-voice.mjs

# 4) 语音 WSS（本地沙盒 + 新 localhost.run 隧道）
node qa/run-tunnel-ws.mjs

# 5) WebKit/Safari 引擎冒烟
python qa/run-https-webkit.py

# 5) 原始 URL 对照
curl.exe -k -sS -m 10 -o NUL -w "code=%{http_code} error=%{errormsg}`n" https://192.144.159.220:8080/play
curl.exe -s -m 10 -o NUL -w "http=%{http_code}`n" http://192.144.159.220:8080/play
```

## 6. 判定

- T1 失败（TLS 不可用）是**预期**，用于说明原始 URL 不能直接改 HTTPS。
- T2–T8 必须通过；T6 缓存 <15s。
- T9 必须直接进牌桌，不能出现警告页。
- T10 若 502/URL 变化，标记「临时不稳定」，不判生产通过。
- 真机/双人语音/24h 不在本轮，标记未覆盖。

## 7. 风险与降级

| 风险 | 说明 |
|---|---|
| localhost.run 免费隧道 | 可能 502、URL 变；需重启换 URL |
| 首载 20–30s | 1.35MB 经海外隧道分块；二次缓存 2s |
| Edge 假麦克风 | 只证明 API/安全上下文，不证明真机音质 |
| 第三方 TLS | 登录明文在隧道端可见；只用测试账号 |
| 旧 SW 不注册 | loader 在 load 后写入；离线不在范围 |
| 生产版本变化 | 本轮探测为 1.1.14；URL/内容随生产更新 |
