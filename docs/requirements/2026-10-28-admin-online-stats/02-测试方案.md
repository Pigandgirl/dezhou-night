# 后台在线玩家与用户管理增强测试方案

## 数据准备

- 3个在线账号：在线甲、在线乙、在线丙；
- 1个离线账号：离线丁；
- 在线甲、在线乙进入同一好友房并开局；
- 3个账号上报 presence。

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-ADM-01 | 打开概览 | 在线玩家=3，显示在线甲/乙/丙 |
| T-ADM-02 | 查看进行中游戏 | 1局，显示房间和在线甲、在线乙 |
| T-ADM-03 | 用户管理筛选在线 | 只显示3个在线账号 |
| T-ADM-04 | 按筹码降序 | 8000、5000、120 |
| T-ADM-05 | 查看当前房间 | 在线甲1号位、在线乙5号位 |
| T-ADM-06 | 查看最后活跃 | 显示时间 |
| T-ADM-07 | 页面错误 | 0 |
| T-ADM-08 | 部署 | 1.1.24 |

## 通过标准

- 概览不再出现“有在线玩家但显示0”；
- 有开局时进行中游戏≥1；
- 用户名/昵称/房间/座位/状态均可读。
