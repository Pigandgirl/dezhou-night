# 筹码、生涯与荣耀系统测试方案

> 状态：评审版  
> 日期：2026-10-25  
> 前置：开发完成；未开发不执行。

## 1. 范围

- 好友房获胜/打平 +5 大厅筹码；
- 单机 +2 筹码/分钟；
- 大厅 +1 筹码/分钟；
- 每日上限、幂等、防刷；
- 生涯页面与统计；
- 筹码流水；
- top3 好友/亲密度；
- 称号解锁、装备、动效、音效、语音；
- 旧账号兼容；
- 回归与发布门禁。

不在范围：

- 真实支付；
- 筹码转账；
- 全量牌局回放；
- 商业游戏原版音频。

## 2. 测试策略

| 层级 | 内容 | 工具 |
|---|---|---|
| 单元 | 奖励计算、幂等、上限、亲密度、称号条件 | Node test/引擎测试 |
| 接口 | `/api/career`、`/api/progress/tick`、称号装备 | fetch |
| 集成 | 好友房结算、在线匹配、生涯更新、事件推送 | Playwright 多用户 |
| UI | 生涯页、称号墙、解锁动画、移动端 | Playwright + 截图 |
| 音频 | 解锁音效/语音、静音 | 真机/浏览器 |
| 性能 | 解锁动画 FPS、包体 | DevTools |
| 安全 | 伪造奖励、重复领取、越权查看 | 抓包/接口 |

## 3. 环境与数据

- 服务端本地QA/staging；
- 账号：A/B/C/D，A为测试主账号；
- 好友房2/4人；
- 在线匹配2人；
- 时间加速：测试环境允许将1分钟缩短为5秒，但生产必须60秒；
- 数据种子：清零/预设生涯；
- 设备：桌面 + Android横屏；
- 音频：开启/关闭语音两种。

## 7. 通过标准

- 经济：AC1-AC10全过；
- 生涯：AC11-AC20全过；
- 称号：AC21-AC30全过；
- 稳定性：AC31-AC35全过；
- 有失败则阻断发布；
- 视觉/音频主观项需产品确认。

## 8. 风险

- 奖励上限/测试时间加速可能掩盖真实经济问题；
- 称号条件需要构造牌型，测试成本高；
- 旧账号迁移可能影响登录；
- 解锁动画/音频需真机验证；
- 防刷无法彻底阻止多账号互刷，只能限额。
