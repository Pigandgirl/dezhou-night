# 筹码、生涯与荣耀系统方案

> 状态：需求评审稿  
> 日期：2026-10-25  
> 结论：先确认经济规则与上限，再开发、测试、验收；未验收不部署。

## 1. 设计原则

1. **大厅筹码**与**牌桌内筹码**必须分开：
   - 大厅筹码 `chips`：账户资产，用于在线匹配入场/结算；
   - 牌桌筹码 `playChips/stack`：本房间本局使用，不直接等于账户资产。
2. 新增获取方式不能破坏现有每小时筹码补给规则。
3. 任何奖励必须服务端判定、幂等、每日有上限。
4. 生涯数据只统计真实对局（好友房/在线匹配），单机只用于练习积分。
5. 称号由服务端解锁，客户端只展示，不能伪造。
6. 解锁动画/音效要酷，但不能影响牌局操作和结算阅读。
7. 不使用《黑神话：悟空》《英雄联盟》的受版权保护音频/原句；使用原创文案与合成音效，风格借鉴。

## 2. 货币模型

### 2.1 两种数值

| 字段 | 名称 | 获取 | 用途 |
|---|---|---|---|
| `chips` | 大厅筹码 | 每小时补给、好友房获胜奖励、活动奖励 | 在线匹配；大厅可见；可消耗 |
| `points` | 生涯积分 | 单机练习、大厅停留、生涯里程碑 | 生涯等级/排行榜/称号进度；不直接消耗 |

> 用户原话中「2筹码」「1筹码」与「大厅筹码」存在混用。本方案默认单机/停留给 **积分**，好友房给 **筹码**。如果产品希望单机/停留也直接给大厅筹码，只需调整奖励配置，但需要重新评估匹配经济。

### 2.2 获取规则

| 来源 | 奖励 | 频率 | 前置条件 | 上限 |
|---|---|---|---|---|
| 好友房每手获胜/打平 | +5 大厅筹码 | 每手每人一次 | 至少2名真实账号；已结算；非弃牌 | 每日100筹码 |
| 单机 AI 对局 | +2 筹码 | 每分钟 | 单机牌桌进行中、页面可见 | 每日120筹码 |
| 大厅停留 | +1 筹码 | 每分钟 | 登录、在大厅、页面可见、非对局 | 每日60筹码 |
| 原有每小时补给 | 补足到配置值 | 每小时检测 | 低于 grant | 按现有规则 |

### 2.3 好友房发奖

- 结算时 `room.match === false`；
- `room` 至少2名不同真实账号；
- 每个 `winners[].seat` 对应玩家 +5 chips；
- 打平：所有分得底池的玩家各 +5（不是按份额乘5）；
- 同一手同一账号只发一次；
- 弃牌玩家不发；
- 房间中途加入、未参与本手不发；
- 防刷：每日好友房奖励上限100筹码；达到上限只记录不再加。

### 2.4 单机筹码

- 每满60秒 +2筹码；
- 每满10分钟弹一次「本局练习已获得 X 积分」提示；
- 页面隐藏、暂停、退出单机立即停止累计；
- 服务端以会话心跳结算，不能只信客户端传的分钟数；
- 每日上限120筹码。

### 2.5 大厅停留积分

- 每满60秒 +1筹码；
- 仅大厅可见、已登录、未在牌局/房间/后台；
- 页面隐藏立即停止；
- 每日上限60筹码。

### 2.6 兼容现有规则

- 现有每小时筹码补给继续保留；
- 好友房奖励是额外筹码，不替代补给；
- 不做筹码转账，避免洗钱/刷分。

## 3. 生涯系统

### 3.1 生涯入口

大厅个人资料卡增加「生涯」按钮，位于「后台管理」同级但普通玩家可见。

### 3.2 生涯页面

```text
┌──────────────────────────────────────┐
│ 生涯 · 德扑之夜                       │
│ [总览] [牌型] [好友] [称号] [流水]    │
├──────────────────────────────────────┤
│ 当前筹码  / 历史最高筹码               │
│ 总对局 / 胜场 / 胜率 / 当前连胜 / 最高连胜 │
│ 称号墙 / 最近解锁                      │
│ 牌型分布柱状图                         │
│ 最常一起玩的3位玩家 + 亲密度           │
│ 最近筹码变化流水                       │
└──────────────────────────────────────┘
```

### 3.3 生涯数据

```text
career: {
  hands, wins, ties, losses,
  winRate,
  handTypeWins: {
    royalFlush, straightFlush, fourOfKind, fullHouse,
    flush, straight, threeOfKind, twoPair, onePair, highCard
  },
  biggestPot,
  highestChips,
  currentStreak,
  bestStreak,
  companions: [{ username, name, hands, winsTogether, intimacy, lastPlayedAt }],
  achievements: [{ id, unlockedAt, progress }],
  titles: [id],
  activeTitle,
  chipLedger: [{ at, delta, balance, source, roomCode, handNo }]
}
```

- 只统计好友房/在线匹配的已完成手牌；
- 单机 AI 不计入胜场/牌型；
- 一手牌多个赢家（平局）每人计1胜；
- 全弃牌获胜：计入胜场，但牌型记为 `foldWin`，不伪造牌型；
- 牌型由服务端结算结果产生；
- 当前筹码取账户 `chips`；历史最高在每次筹码变化时更新。

### 3.4 最常玩的玩家与亲密度

- 按同房同手出现次数统计；
- 亲密度公式建议：

```text
intimacy = min(100,
  handsTogether * 1 +
  winsTogether * 2 +
  daysTogether * 3
)
```

- 展示前3名；
- 只展示自己视角，不暴露对方隐私；
- 同一账号多设备/多昵称按 username 归一。

### 3.5 筹码流水

- 最近50条；
- 来源：`refill`、`friend_win`、`friend_tie`、`admin`、`match_buyin` 等；
- 显示时间、变化、余额、来源；
- 不显示对手底牌。

### 4.2 解锁与装备

- 服务端在结算后计算解锁；
- 解锁幂等：同一账号同称号只解锁一次；
- 解锁后写入 `career.achievements/titles`；
- 生涯页可查看已解锁/未解锁条件；
- 可装备一个当前称号，显示在玩家名牌/房间列表；
- 称号不提供属性加成，避免 pay-to-win。

### 4.3 解锁展示

结算页在牌局结果之后显示：

```text
荣耀解锁
恭喜 玩家名
解锁称号「大杀四方」
三连胜，无人能挡
[继续]
```

- 多个称号排队播放，每个3-4秒；
- 点击/按键可跳过当前；
- 解锁音效：金色合成器 + 低频冲击 + 人声播报；
- 动效：金色粒子、称号卡展开、光扫；
- 语音：`恭喜 {name} 解锁称号 {title}`；
- 尊重静音设置；关闭语音时只显示字幕；
- 不阻塞“继续下一把”操作，动画队列可跳过。

### 4.4 连胜播报

- 在结算时播报当前连胜；
- 2/3/4/5/7/10连胜使用专属称号；
- 中文/英文术语随机混用（与上一轮术语系统一致）：
  - `三连胜，大杀四方` / `Three wins in a row, unstoppable`
  - `五连胜，势如破竹` / `Five wins, on fire`
- 不使用受版权保护的固定音频；文案可采用通用竞技表达。

## 5. 数据与接口

### 5.1 账号

- `user.points`
- `user.chips`
- `user.career`
- `user.achievements`（可合并进 career）
- `user.activeTitle`

### 5.2 API

- `GET /api/career`：返回当前用户生涯、称号、流水、top3好友；
- `POST /api/career/title`：装备/卸下称号；
- `POST /api/progress/tick`：单机/大厅活跃心跳，服务端按分钟结算；
- `GET /api/career/achievements`：可选独立接口；
- 事件：`career_update`、`achievement_unlocked`、`chips_awarded`。

### 5.3 结算联动

- `GameEngine.finish()` 返回 winner/handType/pot；
- 好友房发奖在服务端 `onSettle` 后执行；
- 生涯统计在服务端写入；
- 解锁结果随 `career` direct 事件发送到对应玩家；
- 客户端在结算面板上方排队展示。

## 6. 防刷与边界

| 风险 | 措施 |
|---|---|
| 好友房互刷筹码 | 每日100上限；至少2真实账号；每手一次 |
| 单机挂机 | 仅可见单机牌桌计时；每日120上限；10分钟提示 |
| 大厅挂机 | 仅大厅可见计时；每日60上限 |
| 多设备刷时长 | 服务端会话去重，同一账号只算一个活跃会话 |
| 伪造牌型 | 服务端结算生成，不接收客户端上报 |
| 称号伪造 | 服务端解锁，客户端只读 |
| 称号动画影响操作 | 可跳过；队列不阻塞继续 |
| 经济通胀 | 每日上限；当前每小时补给保留；后续可调配置 |

## 7. 分阶段

### Phase 1：经济与生涯数据

- 好友房+5筹码；
- 单机+2筹码/分钟；
- 大厅+1筹码/分钟；
- 生涯数据、流水、每日上限；
- 生涯页面总览/牌型/好友/流水。

### Phase 2：称号与解锁

- 牌型/连胜/四大名著称号；
- 解锁事件；
- 解锁动效/音效/播报；
- 称号装备与展示。

### Phase 3：丰富化

- 更多称号条件；
- 赛季/排行榜；
- 操作历史/牌局回放（本轮不开发）。
