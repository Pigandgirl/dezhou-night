# 发言状态移入在线名单测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-ROST-01 | 进入在线牌局 | 右侧显示“在线 N” |
| T-ROST-02 | 多人发言 | 在线入口出现发言人数 |
| T-ROST-03 | 点开在线入口 | 面板显示玩家/状态/发言 |
| T-ROST-04 | 开局后 | 状态显示游玩中 |
| T-ROST-05 | 等待/观战玩家 | 状态显示等待入座/观战中 |
| T-ROST-06 | 3人发言 | 对应行显示发言中 |
| T-ROST-07 | 顶部 | 无发言横条 |
| T-ROST-08 | 页面错误 | 0 |

## 通过标准

- 面板宽度固定，不撑满顶部；
- 发言昵称只出现在面板列；
- 状态与在线入口计数正确。
