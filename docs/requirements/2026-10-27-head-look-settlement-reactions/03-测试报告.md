> 版本：1.1.17（versionCode 124）

## 1. 头部跟随

初始：

```text
第一对手 headGroup.rotation.y = -0.678
camera.position.x = 0
```

改变摄像机水平位置后：

```text
camera.position.x = 0.078
headGroup.rotation.y = -0.692
```

头部yaw随摄像机变化，并限制在 ±0.7 弧度内。

实现：

- 每帧计算头部世界位置到相机的水平夹角；
- 减掉座位朝向得到本地yaw；
- 平滑插值到目标角度；
- 保留待机呼吸、眨眼。

## 2. 结算动作

直接触发 `scene.reactSettlement(new Set([1]))`：

```text
reactionActive = true
reactionArms.visible = [true, true]
reactionFeet.visible = [true, true]
avatarGroup.position.y = 0.0216
```

说明：

- 额外拳头/手臂和脚部出现；
- 身体上下弹动；
- 赢家抬头、输家低头；
- 动画结束后隐藏并复位。
