# 底牌左上角常显需求文档

## 背景与问题

底牌面板已从手机左下角移到了左上角标题右侧，但旧逻辑仍保留：

- `beginAction()` 调用 `setCardViewerTurnHidden(true)`；
- MutationObserver 根据行动条显示状态隐藏底牌；
- CSS `#hud.hero-action-open .card-viewer { display:none }`；
- CSS `#hud:has(#actionbar:not(.hidden)) .card-viewer { display:none }`。

结果：用户一到下注、跟注、弃牌操作，左上角底牌就消失。用户明确要求底牌在左上角一直显示，因为该位置不会遮挡牌桌操作。

## 目标

- 底牌面板固定在左上角标题右侧；
- 行动条显示时仍显示底牌；
- 下注、跟注、过牌、加注、弃牌时仍显示；
- 结算时仍显示；
- 手机端和网页端一致；
- 不改变底牌大小、牌面数据、切牌、收起交互。

## 需求点

- **R1** 移除行动条导致的底牌隐藏逻辑。
- **R2** 移除 `hero-action-open` / `:has(#actionbar)` 的底牌隐藏 CSS。
- **R3** 移除行动状态 MutationObserver 对底牌的折叠。
- **R4** 结算时不再隐藏底牌。
- **R5** 保留用户手动「收起」的折叠能力；手动收起属于用户选择，不是系统自动隐藏。
- **R6** 手机端和网页端同步更新。

## 非目标

- 不改变底牌左上角坐标；
- 不改变切换视角功能；
- 不改变行动条位置；
- 不改变结算覆盖逻辑。

## 验收标准

- **AC1** 行动条可见时，底牌 `display` 不为 none。
- **AC2** 手机 844×390 操作时底牌仍在左上角。
- **AC3** 桌面 1200×540 操作时底牌仍在左上角。
- **AC4** 结算层打开时底牌仍显示。
- **AC5** 控制台无 JS 错误。
- **AC6** Android 1.0.90 构建通过。
- **AC7** 真机触摸操作需人工确认。

## 风险

- 底牌常显可能与左上角玩家头像有少量视觉重叠，但不遮挡行动条和按钮；
- 手动折叠仍保留，用户收起后不会自动展开。
