# 底牌左上角常显测试方案

## 范围

- 行动条显示时底牌可见；
- 手机 844×390；
- 桌面 1200×540；
- 下注操作期间；
- 结算层；
- 页面 JS 错误；
- Android 构建。

## 不在范围

- 真机刘海安全区；
- 8 人桌头像遮挡；
- 底牌手动收起的视觉细节；
- 发牌动画。

## 测试策略

- Playwright 启动单机牌桌；
- 等待 `#actionbar` 去掉 `hidden`；
- 读取 `#cardViewer` 的 computed display 和 rect；
- 截图；
- 检查控制台 pageerror；
- 构建 APK。

## 用例表

| 编号 | 需求 | 步骤 | 预期 |
|---|---|---|---|
| T1 | R1,R2 | 行动条显示时检查底牌 | display=flex |
| T2 | AC2 | 844×390 | 左上角 x≈150,y≈6 |
| T3 | AC3 | 1200×540 | 左上角 x≈228,y≈8 |
| T4 | R4 | 打开结算 | 底牌仍显示 |
| T5 | AC5 | 控制台 | 无错误 |
| T6 | AC6 | 构建 | 1.0.90 成功 |

## 命令

```powershell
node --check src/hud.js
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

## 风险

- 底牌常显后可能与玩家头像视觉重叠，但不影响点击行动条；
- 手动「收起」仍会隐藏，这是用户主动行为。
