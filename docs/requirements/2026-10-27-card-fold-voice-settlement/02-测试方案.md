# 底牌向上折叠、播报同步、结算切断与横屏提示测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-CF-01 | 点击底牌“收起” | 面板向上隐藏，顶部横向“底牌”标签 |
| T-CF-02 | 点击顶部“底牌” | 面板恢复 |
| T-CF-03 | 连续3个动作播报 | 名称→操作→名称→操作 |
| T-CF-04 | 播报积压 | 速率2.3/2.1/1.8 |
| T-CF-05 | 队列中有结算文本后取消 | 结算不播，后续动作保留 |
| T-CF-06 | 竖屏390×844 | 横屏提示可见 |
| T-CF-07 | 页面错误 | 0 |
| T-CF-08 | 构建部署 | 1.1.10 |

## 环境

- Edge/Playwright；
- 本地server；
- 无真机音频输出验证；
- 语音用可观测桩记录调用顺序和速率。
