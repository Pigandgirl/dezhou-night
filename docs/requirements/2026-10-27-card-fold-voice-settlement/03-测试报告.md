# 底牌向上折叠、播报同步、结算切断与横屏提示测试报告

> 版本：1.1.10（versionCode 116）  
> 日期：2026-10-27  
> 环境：Edge/Playwright，1200×700 与 390×844  
> 无真机音频输出验证

## 1. 底牌向上折叠

实际点击“收起”后：

```text
class = card-viewer collapsed
opacity = 0
顶部按钮 = 底牌
button rect = x280 y0 w58 h23
```

- 面板向上移动并隐藏；
- 顶部出现横向“底牌”按钮，不再向左侧缩；
- 再次点击“底牌”恢复面板。

截图：`evidence/card-up-collapse.png`

### 发现的额外问题

底牌区域原有 `pointerdown` 滑动切牌会 `setPointerCapture`，导致内部“收起”按钮在真实点击中收不到 click（程序化 click 正常）。
已加按钮排除：点击按钮时不启动滑动捕获。

## 2. 播报顺序与语速

可观测语音桩实测：

```text
阿凯(2.30) → raise
小明(2.10) → call
小红(1.80) → check
```

- 名称播完立即接操作；
- 三条播报全部按序完成；
- 队列无积压时1.12倍；
- 积压1/2/3/4+条为1.8/2.1/2.3/2.5倍；
- 名称和操作之间没有额外延时。

## 3. 结算播报提前与切断

- 在线结算：`announceSettlement` 不再 `setTimeout 450`，在结算UI渲染前入队；
- 单机结算：`audio.speakText` 调整到 `showSettlement` 前；
- 文本：`恭喜{赢家}以{牌型}赢得底池 {金额}`；
- 下一局进入 play / 单机新一手开始时 `cancelSettlement()`。

取消测试：

```text
先入队：小刚 allin
再入队：恭喜小刚以两对赢得底池 60（settlement）
调用 cancelSettlement
最终只播：小刚 allin
settlement 未播
```

## 7. 未覆盖/风险

- 真机听感无法验证；测试只验证调用顺序/速率/取消逻辑；
- 服务端 phrase TTS 首次生成仍有约2秒延迟，语音“开始”早于UI但实际出声受网络影响；
- 2.5倍速可能导致音调偏高；
- 浏览器横屏锁定需要浏览器/全屏支持，失败时仅提示。
