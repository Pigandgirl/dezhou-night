## 3. 遗留问题与风险

1. **新会话默认权限**：本会话已是「完全权限」，但新会话默认权限仍由 DSH 设置决定。建议在 **设置 → 通用 → 权限** 选一次「完全权限」；若希望写死在插件里，需要改权限配置（会覆盖用户选择，未擅自做）。
2. **没有真正的开关**：`/full off` 只返回关闭指引，模式是常开的。真实开关需要会话状态 + 投影 + 胶囊切换，属下一版范围。
3. **Token 成本**：每个请求固定增加 1039 字符（约 700–1000 tokens），纯问答也带这段。
4. **引导而非强制**：段落无法阻止模型漏写文档。若要硬约束，可再加一个校验工具（例如 `delivery_check` 检查四份文件是否存在、验收表是否齐全）。
5. **仅 Web 客户端有徽标**：非 Web 客户端（ACP / headless）只有提示词段落，没有徽标。
6. **界面渲染未目视**：见 AC6。请在页面上看一眼输入框下方是否出现「全量模式 · 需求 → 测试方案 → 测试报告 → 验收报告」。

## 4. 使用方式

- 直接说需求即可，模式默认生效；交付完成后回复里会给出四份文档链接。
- `/full`：查看完整规范与目录约定。
- 关闭：**设置 → 插件 → 停用「全量模式」**（提示词段落与徽标同时消失）。
- 文档位置：`docs/requirements/<日期>-<短名>/`，本次即本目录。
