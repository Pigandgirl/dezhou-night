# 测试方案：DSH「全量模式」

对应需求：[01-需求文档](01-需求文档.md)（R1–R9 / AC1–AC8）

## 1. 测试范围

被测对象：插件包 `D:\software\project\dezhou\.dsh-plugins\full-mode`，以及它在 `web` profile 中的安装与运行时注册。

- 宿主半边：`index.js`（提示词段落、`/full` 命令、子 Agent 跳过判定）
- 客户端半边：`client.js`（composer dock 徽标）
- 打包与清单：`package.json`、`cordis.patch.yml`、`locale/*.json`、`icon.svg`

不在范围：DSH 本体、沙箱/审批服务、其它已装插件、计划的卸载回归（AC7）。

## 2. 测试策略

| 层次 | 方法 | 覆盖 |
| --- | --- | --- |
| 静态检查 | `node --check`、JSON 解析、manifest 字段核对 | 语法与打包完整性 |
| 安装检查 | `plugin_manager install_bundle` 返回的 `application` / `warnings` / `bundle` / `version` | AC1 |
| 持久化检查 | 读取 profile `package.json` | AC1 |
| 宿主注册检查 | `cordis_inspect_query` Host `Config.listConfigs` | 行注册 |
| 提示词端到端 | 解压当前会话日志，定位 `system/message` 事件，确认段落出现在系统提示中 | AC2 |
| 子 Agent 隔离 | 启动一个子智能体，扫描其会话日志 | AC3 |
| 客户端注册 | `cordis_inspect_query` Client `Slots.listSubTree` | AC4 |
| 命令注册 | 插件 `applied` 表示 `apply()` 未抛错；菜单可见性由用户确认 | AC5 |
| 界面渲染 | 无浏览器控制（页面 401 需认证链接），标注未验证 | AC6 |

## 6. 风险与降级

| 风险 | 降级 |
| --- | --- |
| 会话日志是**多帧** zstd，Node 单帧 API 只能解出第一帧（实测仅 209 字节 / 1 事件） | 按 `28 B5 2F FD` magic 切帧逐帧解压 |
| 页面 `http://127.0.0.1:3080` 无 token 返回 401 | 不做自动截图，渲染项标注「未验证」，由用户目视 |
| 卸载验证会破坏已通过的环境 | AC7 本轮不执行，只记录关闭路径 |
| 子 Agent 日志文件名与 id 对应关系需先确认 | 以 `sessions/--D-software-project-dezhou--/session-<id>/` 查找，找不到则该项标注未验证 |
