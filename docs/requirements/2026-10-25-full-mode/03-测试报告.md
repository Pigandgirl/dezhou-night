## 4. 缺陷与修复

| 编号 | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| D1 | 首次安装 `application: failed` | 机器没有 `pnpm`，Plugin Manager 依赖它安装本地包 | `npm install -g pnpm@10` → 10.34.8，重试成功 |
| D2 | PowerShell `ConvertFrom-Json` 报 `Unterminated string` | `Get-Content -Raw` 默认按 ANSI 读 UTF-8 中文，属读取端问题 | 改用 Node 按 UTF-8 读取校验，文件本身合法（无 BOM） |
| D3 | 会话日志直接解压只有 209 字节 / 1 事件 | 日志按追加写成**多帧** zstd，Node 的 `zstdDecompressSync` 只解第一帧 | 按 magic `28 B5 2F FD` 切帧逐帧解压，解出 346 帧 / 573 事件 |
| D4 | 子会话目录按 `session-<id>` 找不到 | 子会话目录名为纯 id（父会话才是 `session-<id>`） | 改为按 id 目录定位后成功 |

## 5. 未覆盖项及原因

| 项 | 原因 | 影响 |
| --- | --- | --- |
| 徽标实际渲染效果（AC6） | 页面 401，缺少可用认证链接，无浏览器控制 | 仅能证明 slot 占用 `active`，像素级渲染未验证 |
| `/full` 在 `/` 菜单的可见性（AC5） | 无执行命令的通道（命令只能由 UI 触发） | 注册成功但菜单展示未验证 |
| 卸载回归（AC7） | 会拆除刚验证通过的环境，本轮不做 | 关闭路径仅以文案说明 |
| 其它 agent preset（minimal / ptc / cordis）下的表现 | 段落为全局注册，未逐个 preset 实测 | 理论一致，未实测 |
| Token 实际增量 | 未做对照请求计量 | 以字符数 1039 估算 700–1000 tokens |
