# 第三人加入后模型缺失与空间错乱修复测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-3P-01 | 2人开局，第三人加入当前手 | 现有玩家 seats 不重建 |
| T-3P-02 | 本手结束进入下一手 | 3人状态 |
| T-3P-03 | 检查scene.rigs | 2个对手rig |
| T-3P-04 | 检查visible | 两个都true |
| T-3P-05 | 检查默认userZoom | 1.55 |
| T-3P-06 | 截图 | 两个对手同时可见 |
| T-3P-07 | 页面错误 | 0 |
| T-3P-08 | 构建部署 | 1.1.19 |

## 修复方案

`setHeroSeat(index,count)` 新增最小默认视距：

- 3人桌：`userZoom≥1.55`
- 4人桌：`userZoom≥1.3`
- 5人以上：保持1.0，用户可自行缩放

不改变座位顺序，只在3/4人桌开局时自动拉远。
