# 第三人加入后模型缺失与空间错乱修复测试报告

> 版本：1.1.19（versionCode 126）  
> 日期：2026-10-27  
> 环境：本地 server + Edge/Playwright 1400×800  
> 无真机低端性能测试

## 1. 当前手三人加入

```text
2人在局：
  state.seats=2
  scene.rigs=1（1个对手 + 第一视角自己）

第三人加入当前手：
  waiting=true
  当前 state.seats 仍为2
  现有两人场景没有重建
```

## 2. 下一手三人

```text
state.seats=3
scene.rigs=2
visible=[true,true]
pageerror=0
```

## 3. 根因确认

第三人视角旧截图只看到一个对手：

- rig 实际存在；
- 默认 userZoom=1，3人桌另一名对手在相机背后/取景框外；
- 不是服务器删除模型，也不是第三人加入把模型清掉。

## 4. 修复

3人桌默认自动拉远：

```text
userZoom = 1.55
```

实际渲染：

```text
playerCount=3
hero=seat2
rigs=2
visible=[true,true]
两个对手都在截图画面内
```

截图：`evidence/three-player-framed.png`
