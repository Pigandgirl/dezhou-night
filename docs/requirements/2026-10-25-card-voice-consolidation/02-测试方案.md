# 底牌位置与麦克风入口整合测试方案

## 范围与不在范围

### 范围内

- 手机横屏 844×390 底牌位置；
- 桌面 1200×540 底牌位置；
- 不遮挡左下行动条；
- 顶部语音入口数量；
- 单图标麦克风；
- 语音弹窗与右上角关闭 X；
- 主开关绿色状态；
- 「只听不发言」；
- 原有语音测试/禁音功能不回归；
- Android 构建。

### 不在范围

- 真机刘海安全区；
- iOS；
- 真实触摸操作延迟；
- 多分辨率穷举（只覆盖 844×390 与 1200×540）。

## 测试策略

- Playwright 建两个账号同房；
- 强制进入游戏 HUD 并调用 `setVoiceAvailable(true)`；
- 测量 `#cardViewer` 的 `getBoundingClientRect()`；
- 点击 `#btnVoice` 验证弹窗；
- 检查 `#btnVoicePanel` 是否存在（应为 false）；
- 点击主开关验证 class/state/enabled/listening；
- 点击 X 验证关闭；
- 构建 APK。

## 环境与数据

- Windows、Edge Chromium、Playwright；
- 844×390 手机横屏视口；
- Chromium fake microphone；
- 源版本 1.0.88 / code 89。

## 用例表

| 编号 | 需求 | 步骤 | 预期结果 |
|---|---|---|---|
| T1 | R1,R2 | 844×390 打开牌桌，测量底牌 | x≈150、y≈6，不再在左下 |
| T2 | R2 | 检查 actionbar 与底牌 | 上下不重叠 |
| T3 | R3 | 查询 `#btnVoicePanel` | 不存在 |
| T4 | R4 | 读取 `#btnVoice` innerText | 空，只有图标 |
| T5 | R5 | 点击麦克风图标 | `voicePanelModal` 打开 |

| T8 | R7 | 点击「只听不发言」 | 麦克风关闭，listening 保持 |
| T9 | R9 | 打开发送/接收包计数 | 仍显示 |
| T10 | AC10 | build-apk.ps1 | 1.0.88 构建成功 |

## 命令清单

```powershell
node --check src/hud.js
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

## 风险与降级

- 底牌置于顶部可能与 8 人桌头像重叠：目前 x150/228 处于标题与中央之间，需真机确认；
- 语音弹窗在低高度设备需要滚动，X 固定在弹窗右上角；
- WebSocket 语音和抖动缓冲链路保持 1.0.87 实现，不做回归修改。
