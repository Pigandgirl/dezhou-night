# 退出单机后立即重进相机测试报告

## 环境与版本

- 日期：2026-10-25
- 版本：1.0.97（versionCode 98）
- 浏览器：Edge / Playwright
- 视口：1200×540
- 真机：无

## 实际输出

```text
起始：
mode = hero
camera = [0, 1.3019197250399852, 1.22]

执行：
toLobby(1900ms)
120ms 后 enterTable(1350ms)
等待两个 Promise + 200ms

最终：
mode = hero
camera = [0, 1.3005736817386835, 1.22]
heroCamBase = [0, 1.3, 1.22]
distance = 0.0005736817386834403
transitionToken = 3
pageerror = 无
```

位置误差 **0.00057**，远小于 0.01；旧 toLobby 没有把 mode 改回 lobby。

截图：`evidence/camera-reentry-fixed.png`。

## 代码修复

1. `this.cameraTransitionToken` 初始化0；
2. `toLobby` 和 `enterTable` 开始均 `++this.cameraTransitionToken`；
3. update 回调 token 不匹配直接 return；
4. complete 回调 token 不匹配不设置 mode/不覆盖 promise；
5. `enterTable` 不再复用旧 toLobby promise；
6. 完成时强制设置目标 position/FOV/look。
