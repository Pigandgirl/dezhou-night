# 退出单机后立即重进相机测试方案

## 范围

- toLobby/enterTable 竞态；
- camera token；
- 最终 mode/position/FOV；
- 页面错误；
- 构建。

## 不在范围

- 真实手机快速点击节奏；
- 正常大厅动画视觉回归；
- 相机手势。

## 策略

- Playwright 进入单机，等待 hero 机位；
- 记录 heroCamBase；
- 调用 `toLobby(1900)`；
- 120ms 后调用 `enterTable(1350)`，模拟立即重进；
- 等待两个 promise 完成 +200ms；
- 断言 mode=hero、位置误差<0.01；
- 截图；
- 构建。

## 用例表

| 编号 | 需求 | 步骤 | 预期 |
|---|---|---|---|
| T1 | R1-R4 | toLobby 后120ms enterTable | 最终 hero |
| T2 | AC2 | 位置距离 | <0.01 |
| T3 | AC3 | 旧 promise完成 | mode不变成lobby |
| T4 | AC6 | pageerror | 空 |
| T5 | AC7 | 构建 | 1.0.97 |

## 命令

```powershell
node --check src/scene.js
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

## 风险

该方法直接复现转场竞态，不等同于真实退出按钮全流程；真机仍需快速操作复测。
