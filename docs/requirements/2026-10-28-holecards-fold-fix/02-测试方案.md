# 好友房底牌重复与弃牌残留测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-CARD-01 | 3人开局 | holeSeats=3, holeCards=6 |
| T-CARD-02 | 检查空座位 | 0张底牌 |
| T-CARD-03 | 一名玩家弃牌 | 该座位 holeCards=0 |
| T-CARD-04 | 弃牌后其他玩家 | 仍各2张 |
| T-CARD-05 | 2–8人 | holeCards=2×人数 |
| T-CARD-06 | 截图 | 每玩家一副牌 |
| T-CARD-07 | 页面错误 | 0 |

## 修复点

- `dealHoleCards` 只遍历 `serverByDisplay` 中真实存在的座位；
- `foldSeat` 立即 `cards.remove()`，不再等muck动画；
- 状态层增加 `discardHoleCards(seat)` 同步清空。
