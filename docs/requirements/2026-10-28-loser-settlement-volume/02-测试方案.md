# 输家/观战结算显示与语音音量测试方案

## 结算用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-SET-01 | 2人全下，房主输掉 | 房主变观战 |
| T-SET-02 | 输家收到 state | settlement非空 |
| T-SET-03 | 查看结算层 | hidden=false |
| T-SET-04 | 内容 | 赢家、底牌、牌型、+筹码 |

## 音量用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-VOL-01 | 默认 | large, gain=3 |
| T-VOL-02 | 小 | gain=1 |
| T-VOL-03 | 中 | gain=2 |
| T-VOL-04 | 大 | gain=3 |
| T-VOL-05 | 特大 | gain=3.5 |
| T-VOL-06 | 超大 | gain=4 |

## 通过标准

- 输家结算可见；
- 音量档位与gain一致；
- 页面无JS错误。
