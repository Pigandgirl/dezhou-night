> 环境：本地 server + Edge/Playwright 1400×800

## 1. 输家结算

测试：2人起始筹码20，双方全下，房主输光。

```text
输家 stack=0

state.settlement=true

```

```text

```

截图：`evidence/loser-settlement.png`

## 2. 音量

实测：

```text
默认 large → gain=3
small → gain=1
medium → gain=2
large → gain=3
extraLarge → gain=3.5
huge → gain=4
```

设置选择“特大”后：

```text
level=extraLarge
gain=3.5
localStorage pokerVoiceVolume=extraLarge
```

截图：`evidence/voice-volume-setting.png`

## 4. 说明

- 输家结算修复原因是 `spectatorState()` 把 `settlement` 强制置空；现改为结算阶段保留公开结算。
- 结算语音就绪前有最多约3.5秒的页面升起等待；等待结束后可见。
- 音量为本机持久化设置（localStorage），不是服务端账户字段。
