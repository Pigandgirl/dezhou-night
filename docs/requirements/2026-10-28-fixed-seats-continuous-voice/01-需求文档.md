# 固定8座位与持续语音需求文档

> 状态：已实现并部署 1.1.20  
> 日期：2026-10-28

## 背景

- 2人在线游玩时第三人加入，下一手出现模型错乱/位置对不上；
- 4/5人加入后也有类似问题；
- 玩家希望固定8个座位，先来先占，后来的人只填空位，不重排原有玩家；
- 语音不应限制5秒，点击开启后持续说话，再点关闭。

## 座位规则

固定8个位置，按以下顺序分配：

```text
第1人 → 1号位
第2人 → 5号位（与1号位面对面）
第3人 → 2号位
第4人 → 3号位
第5人 → 4号位
第6人 → 6号位
第7人 → 7号位
第8人 → 8号位
```

内部使用0-based seatNo：`0,4,1,2,3,5,6,7`。

- 已有玩家seatNo永不因新人加入而改变；
- 新人只占空位；
- 当前手进行中加入时仍等待下一手；
- 3/4人桌默认自动拉远，保证两侧对手可见。

## 语音规则

- 点击麦克风开启，持续说话，不自动5秒关闭；
- 再次点击关闭；
- 关闭提示仅“语音已关闭”；
- 不再显示5秒限制提示；
- 服务端同一时间仍只允许一个说话人；
- 关闭语音时向服务端释放说话人占用。

## 验收

- **AC1** 2人座位0/4。
- **AC2** 第三人座位1，前两人不变。
- **AC3** 3/4/5人加入不重排既有座位。
- **AC4** 3人默认zoom≥1.55。
- **AC5** 语音无5秒计时。
- **AC6** 关闭显示“语音已关闭”。
- **AC7** 1.1.20部署。
