# 跨手牌面残留与牌面清晰度测试报告

## 环境与版本

- 日期：2026-10-25
- 版本：1.0.96（versionCode 97）
- 浏览器：Edge / Playwright
- 本地 `scene` 实例测试
- 真机：无

## 实际输出

### 清卡

```text
清空前 CardManager 牌组数：0（测试时该手尚未显示）
scene.clearCards() 后：0
手动向 scene 加入一张旧牌：1
再次 scene.clearCards()：0
```

第二次清卡证明 clearAll 能删除场景中未登记在 hole/board 索引里的牌。

截图：`evidence/clear-all-cards.png`（清空后的桌面）。

### 清晰度

```text
renderDpr = 1.25
window.devicePixelRatio = 2
牌面 texture anisotropy = 16
牌面纹理宽度 = 288px
```

对比旧值：

```text
DPR mid: 1.0 -> 1.25
DPR low: 0.8 -> 1.0
DPR high: 1.4 -> 1.6
纹理最小比例: 0.75/0.55 -> 0.9
anisotropy: 2/1 -> 16
```

### 代码修复

1. `CardManager.clearAll()` 遍历场景删除全部 card group；
2. `scene.clearCards()` 使用 clearAll，不再依赖 hole/board 索引；
3. 新增 `scene.clearBoardCards()`；
4. `updateBoard()` 在 board 清空或变短时撤掉旧公共牌；
5. showdown 回调增加 `currentHand` 判断，旧 hand 不操作新一手。
