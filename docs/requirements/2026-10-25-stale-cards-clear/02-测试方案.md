# 跨手牌面残留与牌面清晰度测试方案

## 范围

- CardManager clearAll；
- scene.clearCards / clearBoardCards；
- updateBoard 清空/缩短；
- showdown 异步 hand 保护；
- 牌面纹理 anisotropy/尺寸；
- DPR；
- 页面错误；
- 构建。

## 不在范围

- 真实连续多手视觉（无真机）；
- 低端机帧率；
- GPU 内存压力；
- 服务器牌局引擎。

## 策略

- Playwright 启动单机牌桌，等待发牌；
- 统计场景中 `userData.card` 牌组数；
- 调用 `scene.clearCards()`，断言归零；
- 手动向场景加入一张旧牌，再 clearCards，断言归零；
- 读取 renderDpr、纹理 anisotropy、纹理宽度；
- 截图；
- 构建。

## 用例表

| 编号 | 需求 | 步骤 | 预期 |
|---|---|---|---|
| T1 | R1,R2 | 发牌后清卡 | 牌组数0 |
| T2 | R1 | 手动加旧牌再清 | 牌组数0 |

| T7 | AC6 | pageerror | 空 |
| T8 | AC7 | 构建 | 1.0.96成功 |

## 命令

```powershell
node --check src/chips.js
node --check src/scene.js
node --check src/online-3d.js
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

## 风险与降级

- DPR提高影响性能：已有低/中/高预设，可按设备降级；
- 若 clearAll 与动画冲突，cardEpoch 继续阻止旧回调落地；
- 真机需测试连续三手。
