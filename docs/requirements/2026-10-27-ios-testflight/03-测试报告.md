## 4. 修复与改动记录

| 编号 | 问题 | 修复 |

| D1 | Swift UI 文案是 mojibake（加载/错误/弹窗中文） | 重写 `WebViewController.swift` 中文字符串 |

## 5. 未覆盖项与原因

- **签名 archive/上传**：没有 Developer Program 材料；不能在 Windows 生成有效签名。
- **TestFlight Processing**：没有上传。
- **TestFlight 安装/90 天**：没有构建可分发给测试者。
- **真机麦克风**：需要在 HTTPS TestFlight 构建 + iPhone 上点击房间语音并授权；
  CI 模拟器无法验证麦克风采集。
- **外部 Beta App Review**：未提交；4.2 风险未验证。
- **App Store 正式上架**：不在本次范围。
