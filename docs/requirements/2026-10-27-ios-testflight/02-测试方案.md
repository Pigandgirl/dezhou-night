# iOS App TestFlight 分发 — 测试方案

- 对应需求：[01-需求文档.md](01-需求文档.md)

- 分发方式：TestFlight，构建 90 天有效

## 1. 范围与不在范围

**在范围：**

- iOS 源码编译（XcodeGen + Xcode 15.4）；
- Info.plist/中文名/麦克风用途/PrivacyInfo；
- 模拟器启动截图；
- TestFlight 工作流 YAML、secret/HTTPS 预检、ATS 例外剥离；
- 测试计划：签名 archive、上传、TestFlight 安装、麦克风、90 天。

**不在范围：**

- 外部 Beta App Review 的通过保证；
- App Store 正式上架；
- 真实账号的证书/密钥生成（需要开发者账号权限）；
- 90 天后自动续期（需重新上传构建）。

## 4. 执行命令

```powershell
# 查看/下载无签名 CI 构建
gh run list --repo Pigandgirl/dezhounight-ios --limit 3
gh run watch 40504903344 --repo Pigandgirl/dezhounight-ios
gh run download 40504903344 --repo Pigandgirl/dezhounight-ios --dir qa/out/ios-testflight-ci

# 解包校验 Info.plist
tar -xf qa/out/ios-testflight-ci/DezhouNight-unsigned-ipa/DezhouNight-unsigned.ipa -C qa/out/ios-testflight-ci/inspect

# 工作流状态
gh workflow list --repo Pigandgirl/dezhounight-ios --all
gh workflow view ios-testflight.yml --repo Pigandgirl/dezhounight-ios

# 正式上传（配置 Secrets 后）
gh workflow run ios-testflight.yml --repo Pigandgirl/dezhounight-ios \
  -f app_url=https://<稳定HTTPS域名>/play
```

## 5. Secrets / Variables

**Secrets：**

- `IOS_DIST_CERT_P12_BASE64`
- `IOS_DIST_CERT_PASSWORD`
- `IOS_APPSTORE_PROFILE_BASE64`
- `APPSTORE_KEY_ID`
- `APPSTORE_ISSUER_ID`
- `APPSTORE_PRIVATE_KEY`

**Variables：**

- `IOS_TEAM_ID`
- `IOS_BUNDLE_ID`（默认 `com.dezhounight.poker`）
- `IOS_PROFILE_SPECIFIER`

详细创建步骤见 [ios/TESTFLIGHT.md](../../../ios/TESTFLIGHT.md)。

## 6. 环境与数据

- Runner：`macos-14`，Xcode 15.4；
- 无签名构建：`CODE_SIGNING_ALLOWED=NO`；
- 模拟器：iPhone 15，iOS 17.5；
- App 版本：`MARKETING_VERSION=1.2.0`；无签名 CI build `1`；
- TestFlight 构建号：工作流默认当前 Unix 时间戳，保证递增；
- App 内容：远程 `/play`（CI 用生产 HTTP 调试；TestFlight 必须 HTTPS）。

## 7. 风险与降级

- **没有 Secrets**：T6–T9 跳过并标记阻塞；不伪造上传成功。
- **没有稳定 HTTPS**：TestFlight 版不做语音内测；或先解决域名/TLS。
- **外部审核**：4.2 拒绝则改内部测试，或补原生能力后重新提交。
- **签名失败**：优先检查 profile 的 Bundle ID、Team、证书是否匹配。
- **构建号重复**：用更大的时间戳/输入值。
