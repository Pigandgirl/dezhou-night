
## 2. 第三人座位镜头修复

第三人玩家：

```text
state.seatNo=[0,4,1]
heroDisplay=1
自己的模型在1号位 visible=true
相机位置约(-2.36, 2.36)
```

相机位于1号位外侧，不再镜像到8号位。根因是相机旋转方向使用
`seatAngle - PI/2`，与座位坐标方向相反；已改为 `PI/2 - seatAngle`。
