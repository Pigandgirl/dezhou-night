# 播报称呼测试报告

> 版本：1.1.4（versionCode 110）  
> 日期：2026-10-26  
> 环境：Edge/Playwright；本地与生产页面；无 Android 真机听感

## 1. 实现

`audio.speak(action, amount, name)` 现在：

1. 先调用 `speakSystemText(name)`，使用当前 profile 的 TTS 音色读称呼；
2. 等待 `380ms + 每字190ms`（最长1900ms）；
3. 再用当前 profile 的离线音色包播放动作+金额；
4. 新动作到来时通过 `speakSequence` 取消上一动作计时，避免叠音。

## 2. 本地实测

```text
a.speak('raise', 150, '阿凯')
a.speak('check', 0, '小明')

names = ['阿凯', '小明']
keys = [
  ['raise','one','hundred','five','ten'],
  ['check']
]
profile = male_deep
pageerror = 0
```

称呼与动作顺序正确，动作走所选音色包。

## 5. 未覆盖/风险

- 称呼 TTS 与离线动作包是不同引擎，音色可能不是 100% 同一人；
- 真机 TTS 读称呼的实际时长可能与估算不同，长名字可能与动作轻微重叠；
- 未做真机连续动作听感；
- 单机模式主角称呼仍可能是“你”。

## 6. 单机主角称呼

启动单机牌桌时传入账号昵称：

```text
playerName = 单机阿凯
version = 1.1.4
```

单机主角不再固定读“你”。

## 7. 结论

称呼已先读，动作后播；本地和生产代码路径验证通过。真机听感/重叠仍需补测。
