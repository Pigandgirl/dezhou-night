# 在线牌局体验升级测试报告

> 日期：2026-10-25  
> 版本：1.0.102（versionCode 103）  
> 结论：P0 视觉/隐私核心与 P1 观战/后台已落地；语音仅完成低码率+VAD，Opus 未落地。

## 实际输出

### 1. 当前操作玩家焦点

```text
scene.setTurn(1)
actorLookOffset = [-0.25201285681488556, 0.02, -0.06636960338312833]
mode = hero
```

水平偏移约 0.25 世界单位，镜头只做轻量视线偏移，不做大幅绕转。

截图：`evidence/actor-focus.png`。

### 2. 观战自由视角

```text
scene.mode = spectator
spectatorBadge visible = true
hud.className = spectator-mode
.card-viewer display = none
```

截图：`evidence/spectator-mode.png`。

自由视角支持：

- 指针拖动水平旋转；
- 上下俯仰限制；
- 滚轮缩放；
- 回到主视角按钮。

### 3. 全弃牌隐私

代码级修改：

```text
game-engine.buildSettlement(showdown=false)
  hole: undefined
  bestCards: []
  handName: ''
  handDetail: ''
  score: []

finish(): broadcastState(Boolean(this.showdown))
online-3d.rebuildShowdown(): if (!state.showdown) return
hud.showSettlement(): 非摊牌不渲染底牌槽
```

真实全弃牌对局抓包未完成，标记代码级验证。

### 4. 后台 90 秒在线

代码级：

```text
SSE req close
  -> 不立即 online=false
  -> 90 秒离线计时
  -> 重连清除计时器
  -> 90 秒仍无重连才 voiceLeave / online=false / transferHost
```

前端连接错误 5 秒内不提示，避免 3-4 秒切后台就弹“已断开”。

### 5. 语音优化

本次实际落地：

```text
16kHz PCM -> 8kHz 单声道
VAD 静音门限 0.008
尾音保留 8 帧
20ms 帧发送
静音超过 8 帧停止发包
```

**未落地 Opus**：当前测试环境 WebCodecs AudioEncoder 不可用，未强行切换到不可靠的编码路径。
