# 在线牌局体验升级测试方案

> 状态：评审版  
> 日期：2026-10-25  
> 关联需求：`01-需求文档.md`  
> 前置条件：开发完成并通过代码审查；未开发前不执行本方案。

## 1. 范围

覆盖：

- 全弃牌结算隐私；
- 摊牌底牌公开范围；
- 筹码/下注/底池显示；
- 当前操作玩家焦点、聚光灯、镜头幅度；
- 自己回合/非自己回合状态；
- 中英术语播报；
- 4人语音性能与网络；
- 切后台恢复与在线宽限；
- 观战自由视角与隐私；
- 构建、部署门禁。

不在范围：

- 完整牌局回放；
- 跨房间观战；
- 自动托管；
- 真实支付/充值；
- 生产数据压测。

## 2. 测试策略

| 层级 | 内容 | 工具 |
|---|---|---|
| 单元 | settlement裁剪、术语选择、计时器、状态机 | Node test脚本/页面evaluate |
| 接口 | state/settlement隐私、在线宽限、语音relay包 | fetch、WebSocket客户端 |
| 集成 | 多人房间、全弃牌、摊牌、观战、断线重连 | Playwright多上下文+QA服务 |
| 真机 | 安卓横屏、后台、语音4人、相机晕动 | ADB+Android APK |
| 性能 | 语音码率、丢包、CPU/内存、SSE延迟 | WebSocket统计、CDP throttle、真机日志 |
| 安全 | 底牌越权、观战越权、抓包检查 | 浏览器Network/WS帧检查 |

## 3. 环境与数据

- 服务端：本地QA或staging，`ADMIN_USER=admin`；
- 客户端：Edge/Chromium最新版、Android 1.0.99+测试包；
- 账号：admin、普通玩家A/B/C/D、观战者；
- 房间：
  - 好友房2人/4人/6人；
  - 在线匹配房；
- 网络：
  - Wi-Fi；
  - 4G；
  - CDP throttle：RTT150ms、2%丢包；
  - 后台切换；
- 设备：
  - 安卓中端（4GB/8GB内存、6.5英寸横屏）；
  - 低端机至少1台；
  - 桌面浏览器；
- 音频：
  - 4个真实麦克风或4个模拟音频输入；
  - 耳机避免回声。

## 5. 性能/安全测试细节

### 5.1 语音码率计算

- 记录客户端发送字节数与接收字节数；
- `kbps = bytes * 8 / seconds / 1000`；
- 4人开麦分别记录每路；
- 要求单路≤24kbps，单客户端下行≤120kbps；
- 静音30秒发送包数接近0。

### 5.2 丢包测试

```text
CDP Network.emulateNetworkConditions:
  latency 150ms
  downloadThroughput 1.5Mbps
  uploadThroughput 750kbps
  packetLoss 2%
```

- 4人开麦10分钟；
- 统计丢音次数、重连次数、牌局操作延迟。

### 5.3 隐私抓包

- 浏览器Network WS帧/EventSource消息；
- 搜索 `hole`、`bestCards`、`score`、`handDetail`；
- 全弃牌/观战必须为空；
- 服务端单元测试直接调用 `buildSettlement(false)`。

### 5.4 后台测试

```text
adb shell input keyevent HOME
等待3/10/60秒
adb shell am start ...（回到App）
记录 online 状态、SSE重连时间、提示文案
```

- 服务端日志记录 offline grace；
- 真机允许系统限制，但必须符合AC24-AC28。

## 7. 结果判定

- **P0**：所有AC1-AC18、AC24-AC28必须通过；任何失败阻断发布。
- **P1语音**：AC19-AC23必须通过；未达标需修复或降级方案。
- **P1观战**：AC29-AC33必须通过。
- **发布门禁**：AC34-AC37全部通过；否则不部署。
- 非关键视觉问题可记录但不阻断，需产品确认。

## 8. 风险与降级

- 语音Opus在旧WebView不兼容：保留低码率PCM回退，但必须限流；
- 后台保活受系统限制：至少做到90秒宽限+回前台重连；
- 聚光灯性能：关闭阴影，只加低成本Sprite；
- 自由视角穿模：做相机半径/高度碰撞；
- 英文资源缺失：回退中文；
- 时间不足：按P0→P1分阶段验收，不允许未验收直接上线。
