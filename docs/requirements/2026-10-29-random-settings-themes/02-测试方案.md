# 设置8种主题随机切换测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-RAND-01 | 连续打开关闭12次 | 主题不同，不连续重复 |
| T-RAND-02 | 检查8张主题截图 | 8种视觉均存在 |
| T-RAND-03 | 开关主题2/5 | 浅色文字可读 |
| T-RAND-04 | 主题6/8 | 桌面双栏 |

| T-RAND-07 | 页面错误 | 0 |

## 通过标准

- 随机主题可重复但不会连续同一款；
- 8套主题全部可渲染；
- 功能ID与逻辑保持不变。
