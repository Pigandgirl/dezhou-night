# VAD自动说话权测试报告

> 版本：1.1.25（versionCode 132）  
> 日期：2026-10-28  
> 环境：本地 server + API语音帧测试

## 1. 服务端抢麦/释放

```text
A发送语音帧：200（获得说话权）
A持有期间B发送：409（拒绝）
A调用release：200
B再次发送：200（获得说话权）
```

证明服务端已从“长期占用”变为可释放的说话权。

## 2. 客户端VAD

实现：

- 峰值 <0.008 不上传；
- 静音保留8帧尾音；
- 连续12帧（约1秒）自动release；
- 已有说话人时，本地继续采集但不上传；
- 对方释放后，下一帧真实语音自动申请；
- 关闭语音发送leave；
- 不再有5秒自动关闭。
