# VAD自动说话权测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-VAD-01 | A、B都开麦但静音 | 不上传 |
| T-VAD-02 | A开始说话 | A获得说话权 |
| T-VAD-03 | A说话时B说话 | B音频被服务端拒绝 |
| T-VAD-04 | A停止约1秒 | A释放 |
| T-VAD-05 | B继续说话 | B获得说话权 |
| T-VAD-06 | A关闭语音 | 立即释放 |
| T-VAD-07 | 检查5秒 | 不自动关闭 |
| T-VAD-08 | 页面错误 | 0 |

## 阈值

- VAD峰值阈值：0.008
- 静音保留尾音：8帧
- 自动释放：12帧（约1秒）
- 同一时间一个说话人

## 通过标准

- 服务端持有者200，非持有者409；
- release后另一人200；
- 客户端不再发送连续静音。
