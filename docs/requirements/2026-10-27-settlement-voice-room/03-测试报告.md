# 结算优先播报、清池留房与语音约束测试报告

> 版本：1.1.13（versionCode 120）  
> 日期：2026-10-27  
> 环境：本地 server + Edge/Playwright；音频桩  
> 无真机麦克风/扬声器

## 1. 结算抢占实测

音频桩：

```text
15:00:02 阿凯名称开始
15:00:02 speakSettlementNow('恭喜小明赢得底池 100')
结果：
  阿凯名称
  恭喜小明赢得底池 100
  raise 操作没有继续播放
  queue=0 busy=false
```

证据：`evidence/settlement-priority.txt`

- `speakSettlementNow` 会取消队列、停止当前音频；
- 结算文本优先播放；
- 未播操作不补播。

## 2. 清池留房

代码调整：

- 好友房 `gameover` 不再隐藏牌桌/结算；
- “房间只剩一个活跃玩家”判断改为按在线房间成员数，不再因其他玩家变为观战而自动返回大厅；
- `scheduleEmptyRoomReturn` 只统计在线成员，不把观战玩家当离开。

**未做完整全下牌局端到端实测**，只完成了代码路径调整。

## 3. 语音约束

已实现：

- 服务端 `voiceClaim`：4秒窗口内只允许一个 pid 发送；
- 第二人发送返回409/WS丢弃；
- 客户端开启麦克风后4秒自动 `disable()`；
- 服务端广播 `voice-active`，客户端显示“昵称 正在说话”；
- 点击麦克风直接 enable/disable，不再打开面板；
- 设置页新增“语音设置”入口和“接收房间语音”开关。

**未完成真机麦克风、多人并发、4秒自动闭麦实测**，只完成代码实现和语法构建。
