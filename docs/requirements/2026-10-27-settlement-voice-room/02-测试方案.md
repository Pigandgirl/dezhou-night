# 结算优先播报、清池留房与语音约束测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-SV-01 | 操作播报中触发结算语音 | 立即清空操作，念结算 |
| T-SV-02 | 全下清池 | 所有人仍在房间，结算保留 |
| T-SV-03 | 两人同时开麦发送 | 第二人被拒绝/不广播 |
| T-SV-04 | 开麦后等待4秒 | 自动关闭麦克风 |
| T-SV-05 | 其他玩家说话 | 显示昵称 |
| T-SV-06 | 点击麦克风 | 直接启停，不弹面板 |
| T-SV-07 | 设置页 | 语音设置入口+接收开关 |
| T-SV-08 | 构建部署 | 1.1.13 |

## 环境

- 本地 server + Playwright；
- 麦克风权限/真机无法在无设备环境完整验证；
- 结算抢占用音频桩；
- 语音单说话人/4秒做代码与服务端逻辑核对。

## 通过标准

- 结算立即抢占且旧操作不继续；
- 清池不自动 exit；
- 语音限制代码路径完整；
- 页面无JS错误；
- 部署可下载。
