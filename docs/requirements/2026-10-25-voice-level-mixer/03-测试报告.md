## 缺陷与修复记录

1. **网页不开麦就听不到**：旧 `handleVoicePcm` 直接 return if `!enabled`。移除该门槛，听/说分离。
2. **关麦后停止收听**：`stopEverything` 无条件 suspend AudioContext。改为关闭麦克风时保留播放上下文。
3. **没有输入反馈**：新增本地电平、远端每玩家电平、麦克风测试分析器。
4. **没有禁音能力**：新增本地 mutedPids / soloPid / globalMuted，播放前过滤。
5. **没有诊断手段**：面板显示上传/接收包数。

## 未覆盖项及原因

- 真实 Android 手机的麦克风与扬声器：当前没有设备；
- 浏览器自动播放策略在真实 App WebView 中的具体表现：已实现 pointerdown 解锁和提示，未真机验证；
- 蓝牙耳机路由、回声消除：不在本次范围。
