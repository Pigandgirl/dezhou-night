# 房间语音测试、电平与禁音需求文档

## 背景与问题

现有房间语音有三个明显问题：

1. 用户无法确认自己的麦克风是否真的在工作；
2. 麦克风按钮只有开关状态，没有声音电平反馈；
3. 手机端说话，网页端没有声音。

排查发现核心原因在前端：

```js
handleVoicePcm(data) {
  if (!this.enabled || !data) return;
  ...
}
```

`this.enabled` 表示“自己的麦克风是否打开”。网页端如果不能打开麦克风（例如 HTTP 页面不是安全上下文），就永远不播放别人发来的 PCM。同时旧逻辑关闭麦克风时会挂起 AudioContext，进一步停止接收播放。

结论：**听和说必须是两条独立通道**。没有麦克风，也应该能听房间语音。

## 用户场景

### 场景 A：测试麦克风

玩家进入牌桌，打开语音面板，点击「开始测试」，对着手机说话：

- 电平条实时跳动；
- 顶部麦克风图标随声音放大；
- 状态显示「麦克风正常，正在收音」；
- 不说话会提示靠近麦克风或检查权限。

### 场景 B：听所有玩家

进入牌桌后默认可以听到所有正在说话的玩家，不需要先开自己的麦克风。

### 场景 C：禁音某个玩家

语音面板列出房间玩家：

- 点「禁音」只屏蔽该玩家；
- 再点「取消禁音」恢复；
- 只影响本机，不通知对方。

### 场景 D：只听一个玩家

某个玩家太吵，或只想听队友：

- 点该玩家「只听」；
- 其他所有玩家静音；
- 再点「取消只听」恢复所有人。

### 场景 E：全部静音

一键「全部静音」，关闭所有玩家声音；按钮变为「恢复全部」。

## 功能需求

- **R1 麦克风测试**：在线牌桌语音面板提供“开始测试/停止测试”，实时显示输入电平、状态和错误原因。
- **R2 电平反馈**：顶部麦克风按钮、面板电平条随本地音量变化；说话时按钮出现放大的声波环。
- **R3 独立收听**：不开自己的麦克风也能接收并播放房间 PCM；关闭麦克风不停止收听。
- **R4 默认听所有人**：进入语音房间后所有玩家默认未禁音、未 solo。
- **R5 逐人禁音**：每个远程玩家可独立禁音/取消禁音。
- **R6 只听一人**：同一时间最多 solo 一个玩家；再次点击取消；重新点别人切换。
- **R7 全部静音**：一键屏蔽全部远程声音；恢复后回到逐人禁音状态。
- **R8 语音诊断**：面板显示“语音上传 X 包 / 接收 Y 包”，用于定位手机是否上传、网页是否接收。
- **R9 自动播放解锁**：无法自动恢复 AudioContext 时提示“点击屏幕任意位置开启语音播放”，任意点击后恢复。
- **R10 不改变现有中继**：继续使用 HTTP POST PCM + SSE 广播，不引入 WebRTC/TURN。

## 交互设计

顶部操作区：

```text
[麦克风按钮：听语音/语音中/电平环] [语音设置按钮] [设置]
```

点击「语音设置」打开面板：

```text
语音与麦克风
默认能听到所有人。可以单独禁音，也可以只听某一位玩家。

[麦克风测试]                    [开始测试]
[========电平条========]
[麦克风正常，正在收音]

房间语音                        [全部静音]
[vpb · 我] 麦克风已关   [我]
[vpa]      正在说话     [禁音] [只听]
...
语音上传 0 包 · 接收 1 包
```

## 边界与非目标

- 禁音/只听是**本机行为**，不修改服务器玩家状态；
- 不支持跨设备持久保存禁音名单；
- 观战者不进入语音列表；
- 不开麦的用户可以听，但不能上传；
- HTTP 网页无法打开麦克风，但仍可收听；
- 不处理设备音量键、蓝牙耳机路由等系统级问题。

## 验收标准

- **AC1**：未开启麦克风时收到 `voicepcm`，仍能播放并增加接收包计数。
- **AC2**：关闭麦克风后 AudioContext 不挂起，仍保持收听。
- **AC3**：语音面板能在手机横屏/桌面打开，并列出房间玩家。
- **AC4**：麦克风测试能显示实时电平和“正常/没有声音/权限失败”状态。
- **AC5**：顶部麦克风按钮随电平变化，说话时出现 speaking 状态。
- **AC6**：禁音、取消禁音、只听、取消只听、全部静音、恢复全部均正确。
- **AC7**：默认没有禁音、没有 solo、可以听到所有声音。
- **AC8**：手机/发送端 PCM 经服务器中继后，网页/接收端能播放。
- **AC9**：Android 编译通过并产出 1.0.86 APK。
- **AC10**：真实手机麦克风与网页实际出声需要真机验证（当前环境无设备）。

## 依赖与风险

- 浏览器自动播放策略：需要一次用户手势解锁 AudioContext；
- Android WebView 权限：沿用原生麦克风权限桥；
- 现有 PCM 中继单包约 2.7KB，性能足够；
- 真实设备回声/音量/蓝牙路由未覆盖。

## 待确认问题

- 无阻塞项；音量环的具体视觉强度可按用户反馈微调。
