# 房间语音测试、电平与禁音测试方案

## 范围与不在范围

### 范围内

- 收听不依赖自己的麦克风；
- 关闭麦克风后继续收听；
- 麦克风测试与输入电平；
- 顶部麦克风图标电平反馈；
- 逐人禁音、只听一人、全部静音；
- 默认全部可听；
- 语音设置面板打开/关闭；
- 发送端 → HTTP PCM → SSE → 接收端端到端；
- Android 构建。

### 不在范围

- 真实手机麦克风音质；
- 蓝牙耳机、扬声器路由、回声消除效果；
- iOS；
- 真实网络丢包压力测试；
- 多人同时说话的混音质量。

## 测试策略

- **单元/前端逻辑**：直接调用 `shouldHear`、`toggleMute`、`toggleSolo`、`setAllMuted`。
- **界面集成**：Playwright 打开语音面板，验证玩家列表、按钮和状态。
- **端到端**：两个页面加入同一房间；A 开启麦克风（Chromium fake device），B 不开启麦克风；检查 B 的 `packetsReceived` 和 `lastReceivedLevel`。
- **麦克风测试**：Chromium `--use-fake-device-for-media-stream`，点击开始测试，检查状态、电平条、AudioContext。
- **构建**：`scripts/build-apk.ps1`。

## 环境与数据

- Windows / Edge Chromium / Playwright；
- Chromium flags：
  - `--use-fake-device-for-media-stream`
  - `--use-fake-ui-for-media-stream`
- 本地 QA 服务；
- 两个测试账号同房间；
- 生产版本：1.0.86 / versionCode 87。

## 将要执行的命令清单

```powershell
node --check src/voice.js
node --check src/hud.js
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

Playwright 内执行的关键断言：

```js
// 未开麦也能收
voiceChat.handleVoicePcm({ from: otherPid, data: base64Pcm });
voiceChat.packetsReceived;   // > 0

// 禁音/只听
voiceChat.toggleMute(otherPid);
voiceChat.shouldHear(otherPid); // false
voiceChat.toggleSolo(otherPid);
voiceChat.shouldHear(otherPid); // true

// 端到端
voiceChat.enable();          // A
voiceChat.packetsReceived;   // B > 0
```

## 风险与降级

- 没有麦克风权限：面板显示权限错误，仍可听别人；
- AudioContext 被浏览器挂起：提示点击屏幕，pointerdown 自动恢复；
- 手机上传失败：面板“语音上传 0 包”可定位；
- SSE 断线：现有在线重连机制负责恢复。
