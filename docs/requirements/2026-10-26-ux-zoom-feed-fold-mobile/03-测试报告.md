# 视角缩放、动态折叠、手机浏览器与弃牌确认测试报告

> 版本：1.1.9（versionCode 115）  
> 日期：2026-10-27  
> 环境：Edge/Playwright，1200×700 与 390×844 竖屏  
> 无真机扬声器听感

## 1. 环境底噪关闭

实测 `audio.startMusic()` 后：

```text
musicOn = true
crackle = null
ambience = null
ambienceTimer = null
```

- 音乐仍正常调度；
- 火焰噼啪/环境白噪声源不再创建。

## 2. 双指缩放


## 3. 左侧动态折叠

```text

```

左缘显示“动态”竖排按钮，点击可恢复；默认不透明度 0.84。

## 5. 弃牌确认

```text
第一次点击弃牌:
  modalVisible = true
  resolved = null

点击“继续这手”:
  modalVisible = false
  resolved = null

再次点击弃牌 → 确认弃牌:
  modalVisible = false
  resolved = { type: 'fold' }
```

键盘 F 也改为先弹确认框；自动超时弃牌不走确认。

## 8. 未覆盖/风险

- 真机扬声器无法判断“沙沙”是否彻底听不见，只能确认噪声源不再创建；
- 真机双指与浏览器工具栏交互未实测；
- 竖屏是浏览器兜底布局，主要游玩仍建议横屏；
- 弃牌确认弹窗会多一步操作。

**音乐保留、环境声关闭；双指缩放远景、动态折叠、手机竖屏行动条、弃牌二次确认均通过。**
