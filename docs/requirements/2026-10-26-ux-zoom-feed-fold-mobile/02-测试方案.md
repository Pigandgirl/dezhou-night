# 视角缩放、动态折叠、手机浏览器与弃牌确认测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-UX-01 | 单机开局，检查音频源 | musicTimer存在，crackle/ambience为空 |
| T-UX-02 | 双指由500px捏到100px | userZoom=2.8，相机拉远 |
| T-UX-03 | 点击“收起动态” | feed opacity=0，左缘显示“动态” |
| T-UX-04 | 点击“动态” | feed 恢复，折叠按钮恢复 |
| T-UX-05 | 390×844 竖屏开局 | actionbar 完整在视口内，下注按钮可点 |
| T-UX-06 | 点击弃牌 | 弹确认框，未发动作 |
| T-UX-07 | 取消 | 关闭弹窗，未发动作 |
| T-UX-08 | 确认弃牌 | 关闭弹窗，发送 fold |
| T-UX-09 | 页面错误 | 0 |
| T-UX-10 | 构建部署 | 1.1.9 |

## 通过标准

- 行动条 `right≤视口宽`、`bottom≤视口高`；
- 弃牌取消无 `resolveAction`；
- 页面无JS错误；
- APK/最新版本可下载。
