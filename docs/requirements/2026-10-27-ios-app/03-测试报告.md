## 4. 缺陷与修复记录

### D1 Service Worker 作用域错误（已修复）

- **现象/根因**：旧代码 `navigator.serviceWorker.register('/play/sw.js', { scope: '/play/' })`
  注册的是 `/play/`，而页面规范地址是 `/play`。SW 控制不到 `/play`，离线重载与
  更新提示都不可靠。
- **修复**：
  - 注册改为 `scope: '/play'`；启动时注销旧的 `/play/` 注册；
  - 服务端 `/play/sw.js` 返回 `Service-Worker-Allowed: /play`；
  - SW 缓存键固定 `/play`，导航请求网络优先、缓存兜底、离线页兜底。
- **验证**：T1.8（响应头）、T3.1–T3.3（scope/controller/cache）、T3.5（断网启动）、
  W4（WebKit SW）全部通过。

### D2 首次安装误报「新版本」（已修复）

- **现象**：首次注册 SW 时，`clients.claim()` 先让 `navigator.serviceWorker.controller`
  变为真，随后 `updatefound → installed` 回调满足「有 controller」的条件，WebKit
  首载时出现了「新版本已就绪」（修复前未单独保留截图；修复后首载截图见
  `evidence/ios-webkit-sheet.png`，无 banner）。
- **修复**：`pwa.js` 记录页面初始 `hadController`；只有首载已被旧 SW 控制时才提示
  更新。首次安装不再弹条。
- **验证**：WebKit 重跑 `evidence/ios-webkit-sheet.png` 首载无 banner；T3.4 强制
  `showUpdateBanner()` 仍能显示，T8 通过。

### D3 XcodeGen 生成 Xcode 16 格式，Xcode 15.4 打不开（已修复）

- **现象**：CI 第一次运行 `40475861481` 在 `xcodebuild -list` 失败：
  `The project 'DezhouNight' cannot be opened because it is in a future Xcode
  project file format (77).`
- **根因**：XcodeGen 2.46 默认 `projectFormat: xcode16_0`（objectVersion 77），
  而 `macos-14` runner 是 Xcode 15.4。
- **修复**：`ios/project.yml` 增加 `options.projectFormat: xcode15_3` 与
  `xcodeVersion: "15.3"`；重建并重跑。
- **验证**：运行 `40476087454` 全部步骤 success；见 `evidence/ci-xcode15-failure.txt`
  与 `evidence/ios-ci-run.txt`。

### D4 模拟器截图方向（非产品缺陷，已处理）

- `simctl io screenshot` 在设备竖屏缓冲下截到了横屏 UI 的旋转图（1179×2556）。
- 保留 `ios-simulator-raw.png`；用 Pillow 旋转 90° 生成
  `ios-simulator-landscape.png`（2556×1179）用于阅读。App 内方向锁定横屏正常。

### D5 未签名 IPA（分发限制，非缺陷）

- CI 用 `CODE_SIGNING_ALLOWED=NO` 生成未签名包；iOS 不允许直接安装未签名 App。
- 交付路径：Sideloadly/AltStore + Apple ID 个人签名（免费 7 天）；或配置
  Apple Developer 证书后打开可选签名 Job/TestFlight。文档已写明，未把包描述成
  「双击安装」或「已上架」。

### D6 生产未发布 / 无 HTTPS（阻塞）

- 生产仍是 1.1.10、HTTP、443 关闭；`DEPLOY_PASS` 未设置，SSH key 被拒。
- 因此 1.2.0 的安装引导、SW 修复、启动图只在本地/测试环境生效，未到线上用户。
- 处理建议：提供 `DEPLOY_PASS` 后执行 `python scripts/deploy_server.py`，再用
  Caddy/Nginx 配 HTTPS，最后重跑 AC14/AC15。
