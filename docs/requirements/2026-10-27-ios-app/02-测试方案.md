# 02 测试方案：iOS 苹果手机用户版 App

- 日期：2026-10-27
- 被测版本：Web/PWA `1.2.0`（versionCode 117）；iOS Shell `1.2.0 (1)`
- 对应需求：`01-需求文档.md` R1–R10、AC1–AC15

## 1. 范围

### 1.1 在测范围

| 模块 | 测试内容 |
|---|---|
| PWA Manifest | `/play` 头部、manifest 字段、图标、24 张启动图 |
| 安装引导 | Safari 三步、非 Safari 提示、设置页入口、不再提示、standalone 隐藏 |
| 桌面模式 | `navigator.standalone`、`display-mode`、`ios-*` class、安全区 |
| Service Worker | `/play` 作用域、`Service-Worker-Allowed`、缓存、离线重载、旧作用域注销 |
| 更新 | 新版本提示、首次安装不误报、点击更新 |
| HTTP/HTTPS | 安全上下文检测、HTTP 警告、无 SW 注册 |
| 原生壳源码 | XcodeGen 工程、Swift 编译、Info.plist、AppIcon、启动屏、麦克风描述 |
| CI 制品 | arm64 未签名 IPA、SHA256、模拟器安装启动截图 |
| 生产探针 | 版本、HTTP 状态、TLS 端口、部署凭据可用性 |

### 1.2 不在测范围

- iPhone/iPad 真机安装、Safari 实际「添加到主屏幕」流程、真机麦克风/音频路由。
- Apple Developer 签名、TestFlight、App Store 审核。
- 生产发布、HTTPS 证书/域名配置（无凭据）。
- Android APK 回归（未改 APK；Web 1.2.0 未打进 APK）。
- 长时间稳定性/弱网/发热/耗电。

## 2. 测试策略

| 层级 | 工具 | 目的 |
|---|---|---|
| 静态资源/HTTP | Node fetch + `curl` | manifest、图标、splash、SW 响应头、状态码 |
| iOS Safari 仿真 | Edge 149 CDP + iPhone 17.5 Safari UA | 安装引导、standalone、Service Worker、离线、HTTP 分支 |
| Safari 引擎 | Playwright 1.62 WebKit 26.5 + iPhone 13 profile | 真实 WebKit 渲染/布局/SW 冒烟 |
| 原生构建 | GitHub Actions `macos-14` + Xcode 15.4 | 编译、打包 IPA、iOS 17.5 模拟器启动 |
| 制品检查 | Python `zipfile` + `plistlib` + Mach-O 头解析 | Bundle ID、版本、最低系统、arm64、ATS、启动屏 |
| 生产只读探针 | `curl`、`Test-NetConnection`、SSH | 确认生产仍 1.1.10/HTTP、443 关闭、无部署凭据 |

> Edge 的 iPhone UA 只是 Chromium 仿真，不等同 Safari；WebKit 也不是 Mobile Safari。
> 两者都通过只能证明「Web 端逻辑与布局大概率正确」，不能替代真机。

## 5. 执行命令清单

以下命令可直接复制重跑（Windows PowerShell，项目根目录）：

```powershell
# 1. 生成 iOS/PWA 图标与 24 张启动图
python scripts/make-ios-assets.py

# 2. 构建 Web 1.2.0（单文件）
$env:APP_VERSION='1.2.0'
$env:APP_VERSION_CODE='117'
npm run build
Copy-Item dist/index.html server/public/web/index.html -Force

# 3. PWA 全量验收（Edge CDP，43 项）
node qa/run-ios-pwa.mjs

# 4. WebKit / iPhone 13 冒烟（7 项）
python qa/run-ios-webkit.py

# 5. 校验 CI 下载的未签名 IPA
python qa/verify-ios-ipa.py ios/dist/DezhouNight-unsigned.ipa

# 6. 查看 iOS CI 运行
gh run view 40476087454 -R Pigandgirl/dezhounight-ios

# 7. 生产只读探针
curl.exe -s -o NUL -w "play=%{http_code}`n" http://192.144.159.220:8080/play
curl.exe -s -I http://192.144.159.220:8080/play/sw.js
Test-NetConnection 192.144.159.220 -Port 443 -InformationLevel Quiet
```

可选：`DZ_LAN_HOST=192.168.x.x` 指定 T9 使用的局域网地址；不设置时脚本自动挑选
`192.168.*` 网卡。

## 6. 判定规则

- 任一 AC 对应主用例失败 → 该 AC 判「失败」，先修复再复测。
- 因缺少外部凭据/设备无法执行的用例 → 判「阻塞」，不计入通过，也不隐藏。
- 截图/日志必须来自本轮真实执行；旧产物不得复用。
- 未执行项必须在 `03-测试报告.md` 的「未覆盖项」中列出。

## 7. 风险与降级

| 风险 | 降级/说明 |
|---|---|
| Edge UA 不是 Safari | 增加 WebKit 真引擎冒烟；真机仍列为未覆盖 |
| WebKit 不是 Mobile Safari | 只证明渲染/脚本路径；safe-area/安装 UI 以真机为准 |
| 模拟器截图方向旋转 | 保留原始图 + 本地旋转图，二者都在 evidence；不作为 UI 缺陷 |
| CI macOS 分钟/额度 | 工作流已成功一次；后续可手动 dispatch，避免每次 push |
| 无签名证书 | 只交付未签名 IPA；安装步骤要求 Sideloadly/AltStore |
| 生产不可发布 | 交付部署命令与依赖；AC14/AC15 标阻塞 |
| HTTPS 未配置 | 明确 HTTP 下无 SW/麦克风；不把安装成功等同语音可用 |
