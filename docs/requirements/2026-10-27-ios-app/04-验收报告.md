## 4. 遗留问题与风险

### 4.1 必须处理（上线前）

1. **生产仍是 1.1.10 / HTTP**
   - 影响：1.2.0 的安装引导、启动图、SW 修复未到线上；iOS 无离线/麦克风。
   - 处理：提供 `DEPLOY_PASS`，先备份 `store.json`/旧 `public`，再执行
     `python scripts/deploy_server.py`；确认 `/play` 1.2.0、`/play/sw.js` 带
     `Service-Worker-Allowed: /play`。
2. **没有 HTTPS**
   - 影响：iOS 不注册 SW、`getUserMedia` 不可用；PWA 离线与房间语音不可用。
   - 处理：配置域名 + Caddy/Nginx/证书；更新 `PUBLIC_ORIGIN`、`DZ_APP_URL`；
     用 HTTPS 重建 IPA；移除 `NSAllowsArbitraryLoads`。
3. **未签名 IPA**
   - 影响：无法直接安装/分发给普通用户；免费 Apple ID 7 天过期。
   - 处理：内测用 Sideloadly/AltStore；公开分发用 Apple Developer + TestFlight；
     App Store 需账号与审核。

### 4.2 未验证（需真机/账号）

- iPhone 真机 Safari「添加到主屏幕」、启动图匹配、刘海/Dynamic Island 安全区。
- 真机麦克风授权、音频路由、后台音频、弱网语音。
- 签名 IPA、TestFlight、App Store 4.2 审核。
- 真实双版本 Service Worker 更新握手（waiting → SKIP_WAITING → reload）；
  本轮只验证了 banner 显示与首载不误报。
- Android APK 回归（APK 未重建）。

### 4.3 其他风险

- **App Store 4.2 最低功能**：当前原生壳远程加载 `/play`，审核可能要求更多原生能力；
  若目标是上架，建议补推送、离线包、原生导航或改用 PWA 分发。
- **ATS 例外**：当前为加载 HTTP 生产而开启 `NSAllowsArbitraryLoads`；上架前必须移除。
- **GitHub 账号/额度**：私有构建仓库使用用户账号与 macOS Actions 分钟；仓库只含
  壳代码，无密钥，可随时删除。另有一个临时探测仓库
  `Pigandgirl/dezhou-ios-ci-probe`（仅验证 macOS runner），当前 token 缺少
  `delete_repo` scope，未能自动删除，可在 GitHub 设置中手动删除。
- **截图方向**：模拟器原始截图是旋转的，已保留 raw 并生成横屏版；不是 App 缺陷。
- **版本不一致**：Web 1.2.0 未打进 Android APK（APK 仍 1.1.10）；服务端
  `latest.json` 仍 1.1.10，客户端 117 ≥ 116 不会被强制更新；如要正式发版需统一版本。

## 5. 发布建议

### 5.1 内测（现在可做）

1. 用 Sideloadly + Apple ID 安装 `DezhouNight-unsigned.ipa`，在 iPhone 上验证启动、
   登录、单机、横屏与刘海安全区。
2. PWA 侧可在本机/内网用 HTTPS 或 localhost 验证；生产 HTTP 下先不承诺离线/语音。
3. 收集真机截图与日志，补充 `03-测试报告.md` 的未覆盖项。

### 5.2 公开测试（需要凭据）

1. 备份生产数据；
2. 发布 Web/PWA 1.2.0 + `server.js` + `sw.js` + manifest + 图标/启动图；
3. 配置 HTTPS 域名；
4. 真机重跑 AC14/AC15（安装、离线、麦克风）；
5. 用 HTTPS 地址重建 IPA，移除 ATS 例外。

### 5.3 上架/TestFlight（需要 Apple Developer）

1. 加入 Apple Developer Program，创建 App ID、证书、Provisioning Profile；
2. 在 GitHub 仓库配置 `IOS_SIGNING=true` 及证书/描述文件 secrets；
3. 打开可选签名 Job，导出 `app-store-connect` 包；
4. 上传 TestFlight，补隐私清单/审核材料；
5. 评估 4.2 风险并补原生能力。

## 6. 最终结论

- **iOS 用户版已做出来**：
  - PWA 安装版（Safari 添加到主屏幕）代码与体验完成；
  - 原生 WKWebView 壳已在 macOS CI 编译出 arm64 未签名 IPA，并在 iOS 17.5
    模拟器成功启动、加载生产牌桌；
  - 51 项自动化检查通过，0 失败。
- **但不能说「全部完成」**：
  - 生产仍是 1.1.10/HTTP，1.2.0 未上线；
  - IPA 未签名，普通用户不能直接安装；
  - 真机、麦克风、TestFlight/App Store 未验证。
- **建议**：按 5.1 先做内测；提供部署凭据与 HTTPS 后完成公开测试；有 Apple
  Developer 账号后再走签名/上架。当前状态适合「内测/侧载」，不适合宣传为
  「App Store 已上架」。
