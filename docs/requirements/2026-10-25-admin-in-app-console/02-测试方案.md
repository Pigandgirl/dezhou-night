# 游戏内后台管理板块测试方案

## 范围

- 按钮不打开浏览器；
- 游戏内控制台开关；
- 概览统计/房间；
- 用户列表/编辑/删除；
- 对局记录；
- 权限开关；
- 基础运维信息；
- 5秒刷新；
- 桌面与手机布局；
- 场景暂停/恢复；
- Android 构建。

## 不在范围

- 生产 admin 游戏密码；
- 真机触摸滚动；
- 删除真实生产用户；
- 多管理员并发；
- 真实房间关闭对局恢复。

## 策略

- 本地 QA 服务 `ADMIN_USER=admin`；
- admin 游戏 token 登录；
- Mock `window.open` 计数，点击后台按钮；
- 检查 admin 屏幕、统计、房间、用户、权限；
- 关闭后检查 hidden；
- 手机 844×390 截图；
- 页面 pageerror；
- 构建；
- 生产页面检查包含 admin screen。

## 环境

- Windows/Edge/Playwright；
- 本地 QA 服务；
- admin/normal 账号；
- 1200×700、844×390；
- 无真机。

## 风险与降级

- API 401时自动关闭后台并提示重新登录；
- 关闭后台恢复场景 paused=false；
- 轮询在 document.hidden 时跳过。
