# 游戏内后台管理板块需求文档

## 背景

上一版 admin 登录后点击「后台管理」会打开 `/admin` 浏览器页面。用户要求：

- 不再弹到浏览器；
- 直接在游戏软件内部做一个完整后台板块；
- 界面和原后台管理一致；
- 可以看统计、对局、用户、房间；
- 可以管理所有权限开关；
- 增加基础运维信息。

## 目标

- admin 账号点击「后台管理」在当前页面打开全屏控制台；
- 不调用 `window.open` / 不离开游戏；
- 后台功能包括概览、用户、对局、房间、权限；
- 5秒自动刷新；
- 手机横屏和桌面都可用；
- 关闭后无缝回到游戏大厅。

## 需求点

- **R1** 新增游戏内 `AdminConsole` 板块，全屏 fixed 层。
- **R2** 复用 `/api/admin/*`，使用 admin 玩家 Bearer token。
- **R3** 概览显示注册用户、在线玩家、进行中游戏、服务器连接、内存、累计对局。
- **R4** 当前房间表格支持查看状态与在线/座位，支持关闭房间。
- **R5** 用户管理支持搜索、分页、编辑昵称/积分/筹码/密码、删除。
- **R6** 对局记录支持分页。
- **R7** 权限开关支持在线总开关、匹配、好友房、筹码间隔、补足目标保存。
- **R8** 基础运维卡显示运行时长、RSS、SSE连接、未结束历史、服务器时间、管理端配置。
- **R9** 概览/房间每5秒刷新，页面隐藏或关闭时停止。
- **R10** 打开时暂停 3D 场景，关闭后恢复，降低后台占用。
- **R11** 后台全屏层不打开浏览器窗口。
- **R12** 手机横屏使用顶部横向导航和单列内容。

## 交互

主大厅右上：

```text
[后台管理]
```

点击后：

```text
┌──────────────┬─────────────────────────────┐
│ 德扑之夜      │ 概览             5s实时刷新 × │
│ 概览          │ [注册][在线][游戏] ...          │
│ 用户管理      │ 当前房间 ...                   │
│ 对局记录      │ 基础运维 ...                   │
│ 房间管理      │                               │
│ 权限开关      │                               │
│ 刷新数据      │                               │
│ 返回游戏      │                               │
└──────────────┴─────────────────────────────┘
```

用户编辑用内嵌表单弹层，不跳出游戏。

## 非目标

- 不删除原 `/admin` 页面，仅改游戏入口；
- 不新增数据库；
- 不增加服务器重启按钮；
- 不改变后台 API 协议；
- 不做实时 WebSocket 推送，使用5秒轮询。

## 验收标准

- **AC1** 点击后台按钮不调用 window.open。
- **AC2** 游戏内全屏控制台打开。
- **AC3** 概览显示6项统计。
- **AC4** 房间列表显示当前4个匹配房并可关闭。
- **AC5** 用户列表可加载、搜索、编辑、删除。
- **AC6** 对局记录可加载、分页。
- **AC7** 权限开关可加载和保存。
- **AC8** 5秒自动刷新。
- **AC9** 手机 844×390 布局可用。
- **AC10** 关闭后回到游戏并恢复场景。
- **AC11** Android 1.0.95 构建通过。
- **AC12** 真机触摸与生产 admin 密码需人工确认。

## 风险

- 用户删除/房间关闭使用系统 confirm，属于危险操作保护；
- 后台层覆盖游戏，若用户强制退出页面会关闭；
- 管理数据以5秒轮询，不是毫秒级实时；
- 真机 WebView 的滚动与安全区需要人工确认。
