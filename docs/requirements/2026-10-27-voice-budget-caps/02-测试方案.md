# 播报硬时限与名称/操作无缝衔接测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-B-01 | 阿凯+call+20 | 总时长≤1.3s，名称结束立即操作 |
| T-B-02 | 小明+fold（无数字） | 总时长≤1.2s |
| T-B-03 | 短句 | rate=1，不无意义加速 |
| T-B-04 | 记录每段实际墙钟 | 不丢名称/操作/数字 |
| T-B-05 | 页面错误 | 0 |
| T-B-06 | 构建部署 | 1.1.12/119 |

## 测量

- 包装 `playBuffer`，记录每次实际开始/结束；
- 总时长=最后一段结束-第一段开始；
- 保留调用顺序和rate。

## 通过标准

- 带数字≤1.3s；
- 不带数字≤1.2s；
- 名称与首个操作段间隔≤50ms；
- 未超预算条目rate=1。
