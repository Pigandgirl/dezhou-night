# 中途加入第一手底牌与多路语音测试报告

> 版本：1.1.29（versionCode 136）  
> 日期：2026-10-29  
> 环境：本地 server + Edge/Playwright 1400×800

## 1. 中途加入第一手底牌

第三人加入等待，进入下一手后：

```text
hand=6
heroHoleHand=6
heroHole=[4♠,7♣]
spectator=false
HUD显示：4♠ 7♣
pageerror=0
```

截图：`evidence/third-first-hand-cards.png`

修复点：

- `setHole()` 不再因为 `spectator=true` 丢弃私牌；
- 仅丢弃 `data.hand < currentHand` 的旧牌；
- 私牌先于正式 state 到达时仍保存，state 建立后显示。

## 2. 多路语音

3个玩家同时发语音帧：

```text
玩家A：200
玩家B：200
玩家C：200
```

不再出现 `409 有人正在说话`。

客户端混音：

```text
remoteTimelines=3
pids=[2,3,4]
playbackGain=3（默认大）
DynamicsCompressor=true
```

三路各自有独立 nextAt，不再串行；通过 compressor 防止叠加破音。

## 3. 服务端

- 移除单人说话权抢麦；
- 最多8人同时说话；
- 语音帧广播给其他客户端；
- 说话人昵称支持数组，麦克风旁显示“A、B、C正在发言”；
- VAD静音仍不上传。
