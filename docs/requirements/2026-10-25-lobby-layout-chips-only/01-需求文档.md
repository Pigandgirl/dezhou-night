# 首页居中、筹码记录与去积分需求文档

## 背景

- 首页左侧标题、用户名、筹码与标题没有垂直居中，整体偏上。
- 生涯中的「流水」名称不好听。
- 用户属性和奖励里的「积分」没有实际用途，需要删除，统一使用大厅筹码。

## 目标

- 首页左侧信息组在大厅垂直居中，内部保持左对齐。
- 生涯「流水」改为「筹码记录」。
- 前台不再显示积分。
- 单机 AI 与大厅停留奖励从积分改为大厅筹码，保留原每日上限数值。
- 好友房每手获胜/打平继续 +5 大厅筹码。

## 需求

- **R1** `.lobby-main` 左列垂直居中。
- **R2** 标题、用户名、筹码信息左对齐。
- **R3** 桌面 1200×700 左列中心与主区域中心一致。
- **R4** 手机 844×390 仍居中且不重叠。
- **R5** 生涯 Tab「流水」改为「筹码记录」。
- **R6** 生涯卡片「筹码流水」改为「筹码记录」。
- **R7** 账号 API 不再返回 `points` 给前台。
- **R8** 生涯页不显示生涯积分。
- **R9** 单机每分钟 2 大厅筹码（原 2 积分）。
- **R10** 大厅停留每分钟 1 大厅筹码（原 1 积分）。
- **R11** 单机每日上限 120 筹码，大厅每日上限 60 筹码。
- **R12** 进度提示显示「筹码」而不是「积分」。
- **R13** 原有好友房 5 筹码和每小时补给不变。
- **R14** 不删除用户内部旧 points 字段，避免旧排行榜/管理数据损坏；前台不再展示。

## 非目标

- 不做筹码转账；
- 不重做排行榜；
- 不删除后台历史积分数据；
- 不修改牌桌内筹码。

## 验收

- **AC1** 1200×700 左列中心差为 0。
- **AC2** 844×390 左列垂直居中。
- **AC3** 生涯 Tab 显示「筹码记录」，无「流水」。
- **AC4** 生涯无「生涯积分」。
- **AC5** `/api/auth/me` 无 points 字段。
- **AC6** 单机 60 秒 +2 大厅筹码，不再 +2 积分。
- **AC7** 大厅 60 秒 +1 大厅筹码。
- **AC8** 单机/大厅每日上限仍为 120/60。
- **AC9** 好友房 5 筹码不变。
- **AC10** 手机/桌面截图无溢出。
- **AC11** 页面无 JS 错误。
- **AC12** 1.0.101 构建并部署。
