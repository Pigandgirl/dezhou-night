# 首页居中、筹码记录与去积分测试方案

## 范围

- 首页左列垂直居中；
- 手机/桌面布局；
- 生涯 Tab 与卡片改名；
- 前台 points 移除；
- 单机/大厅奖励改筹码；
- 每日上限；
- 页面错误；
- 构建部署。

## 用例

| 编号 | 需求 | 步骤 | 预期 |
|---|---|---|---|
| T1 | R1/R2 | 1200×700 打开大厅 | 左列中心与主区域中心一致 |
| T2 | R4 | 844×390 | 垂直居中，不重叠 |
| T3 | R5/R6 | 打开生涯 | Tab「筹码记录」，无「流水」 |
| T4 | R7/R8 | 检查账号/生涯 | 无 points/生涯积分 |
| T5 | R9 | 单机心跳60秒 | +2筹码 |
| T6 | R10 | 大厅心跳60秒 | +1筹码 |
| T7 | R11 | 检查daily | singleChipCap=120，lobbyChipCap=60 |
| T8 | R13 | 好友房胜利 | +5筹码 |
| T9 | AC11 | pageerror | 空 |
| T10 | AC12 | 构建 | 1.0.101 |

## 环境

- Edge / Playwright；
- 1200×700、844×390；
- 本地QA服务；
- 种子账户。

## 命令

```powershell
node --check server/server.js
node --check src/career.js
node --check src/progress.js
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

## 风险

- 旧用户 dailyProgress 里仍是积分字段，已迁移到 chips；
- 旧 points 数据保留但前台不再展示；
- 排行榜为筹码榜，不受影响。
