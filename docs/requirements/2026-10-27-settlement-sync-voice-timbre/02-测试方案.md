# 播报原音色与结算语音/页面同步测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-AV-01 | 单机 AI 播报 | rate全部1 |
| T-AV-02 | 观察音色 | 无加速变调 |
| T-AV-03 | 触发结算并记录时间 | 页面展开与语音开始同步 |
| T-AV-04 | TTS较慢 | 页面等待，不先展示 |
| T-AV-05 | 页面错误 | 0 |
| T-AV-06 | 构建部署 | 1.1.14 |

## 测量

- 包装 `playBuffer` 记录rate；
- 记录 `page-reveal` 与首段结算 `play` 时间；
- 结算音频走真实服务端 phrase TTS。

## 通过标准

- rate=1；
- 页面展开与语音开始差≤100ms；
- 未出现页面先展示后空等。
