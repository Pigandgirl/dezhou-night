# 1–8人在线模型一一对应测试方案

## 用例

| 编号 | 人数 | 预期 |
|---|---|---|
| T-18-01 | 1 | 等待，最少2人开局 |
| T-18-02 | 2 | 2个模型（自己+对手） |
| T-18-03 | 3 | 3个模型 |
| T-18-04 | 4 | 4个模型 |
| T-18-05 | 5 | 5个模型 |
| T-18-06 | 6 | 6个模型 |
| T-18-07 | 7 | 7个模型 |
| T-18-08 | 8 | 8个模型 |

## 方法

- 每个 n 创建独立好友房；
- n-1 个API账号加入并连接SSE；
- 页面账号作为房主；
- 开局后读取：
  - `state.seats.length`
  - `scene.rigs.filter(Boolean).length`
  - hero模型是否存在
  - 是否还有房间遮罩
- 截图 1400×800。

## 通过标准

- 2–8人模型数=玩家数；
- hero模型存在；
- 房间遮罩隐藏；
- 无JS错误。
