# 玩家独立服装与下半身/椅子测试方案

## 用例

| 编号 | 步骤 | 预期 |
|---|---|---|
| T-OC-01 | 单机开局读取7个对手 | 7个独立rig |
| T-OC-02 | 读取outfit.style | 7种不同风格 |
| T-OC-03 | 读取outfit.jacket | 7种不同主色 |
| T-OC-04 | 截图检查 | 髋部/裤腿/鞋可见 |
| T-OC-05 | 截图检查椅子 | 坐垫/扶手/椅腿 |
| T-OC-06 | 页面错误 | 0 |
| T-OC-07 | 构建部署 | 1.1.16 |

## 说明

主角第一视角不生成身体模型；测试7个对手即可覆盖所有玩家服装。
在线8人使用同一 `OUTFITS` 调色板映射，因此在线也保证不同。
