## 使用方式

1. 使用 admin 游戏账号登录主页面；
2. 右上角出现「后台管理」；
3. 点击进入后台；
4. 可查看服务器内存、连接数、在线玩家、进行中游戏；
5. 可进入用户管理、对局记录、房间管理、权限开关；
6. 点「返回游戏」回到大厅。

## 风险

1. 生产 admin 游戏密码未在测试环境中读取/验证，用户需用自己的密码；
2. 后台页面 token 缓存在 localStorage；退出后台只清后台 token；
3. 手机 APK 通过 NativeBridge.openUrl 打开后台，需真机确认外部浏览器行为；
4. 直接 `/admin` 的环境密码登录仍保留。

## 发布建议

发布 1.0.94。上线后建议用 admin 游戏账号实际登录一次，确认：

- 右上角按钮出现；
- 点击后无需二次登录；
- 概览5秒刷新；
- 权限开关保存后游戏客户端15秒内生效；
- 普通账号看不到后台按钮。

## 结论

admin 游戏主账号已与后台管理打通：账号登录后显示后台入口，使用游戏 token 直接进入后台，概览展示服务器与在线游戏数据并每5秒刷新；普通账号后台 API 返回401。核心链路通过本地自动化和生产页面检查，生产 admin 密码与真机入口需人工验证。
