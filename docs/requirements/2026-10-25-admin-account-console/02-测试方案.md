# admin 主账号后台管理集成测试方案

## 范围

- admin 账号 isAdmin；
- 主页面后台入口显隐；
- game token 访问后台 API；
- 普通账号拒绝；
- hash token 自动登录；
- 后台统计信息；
- 5秒实时刷新；
- 返回游戏；
- 构建。

## 不在范围

- 生产 admin 游戏密码验证（密码由用户持有，不能读取/猜测）；
- 多管理员并发；
- 真实手机外链打开；
- 后台所有表单逐项回归（已有功能未改）。

## 策略

- 本地 QA 服务环境设置 `ADMIN_USER=admin`, `ADMIN_PASSWORD=...`；
- 构造 admin / normal 两个游戏账号 token；
- Playwright 打开 `/play`，检查后台按钮和 URL；
- 打开 `/admin#token=...`，检查自动进入和统计；
- 统计6秒内 overview 请求数；
- 直接 fetch 后台 API 验证200/401；
- 检查生产 `/admin` 页面包含新入口；
- 构建。

## 环境

- 本地游戏服务；
- Edge/Playwright；
- admin env；
- 1200×700；
- 生产：`http://192.144.159.220:8080`。

## 风险与降级

- 若 hash token 无效，后台会显示登录页；
- 普通账号只能看到401；
- 后台 localStorage token 失效后自动退出。
