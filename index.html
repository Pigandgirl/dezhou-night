规则与操作

无限注德州扑克

每人两张底牌，与桌面五张公共牌组合出最强的五张牌。经过翻牌前、翻牌、转牌、河牌四轮下注，摊牌比大小。可随时全下，边池自动结算。

快捷操作

  • F 弃牌
  • C 过牌 / 跟注
  • R 按当前金额加注
  • 鼠标 轻微环视牌桌

牌型大小

皇家同花顺 › 同花顺 › 四条 › 葫芦 › 同花 › 顺子 › 三条 › 两对 › 一对 › 高牌

数字牌面

牌面以数字显示：11 = J、12 = Q、13 = K、14 = A。牌角「♠ / ♥ / ♦ / ♣」分别代表黑桃、红桃、方块、梅花。左侧牌面面板可点击「切换」或左右滑动查看底牌与公共牌，也可「收起」只留一个侧边拉手。

关于本局

筹码见底后可重新买入，机器人对手也会补充筹码，牌局会一直继续。你可以随时返回大厅调整人数、筹码与盲注。
